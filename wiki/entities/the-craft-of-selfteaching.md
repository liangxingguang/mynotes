# 《自学是门手艺》

## Overview（概览）

李笑来的 GitHub 开源书，以编程（Python）为入口讲自学方法论：教的不是编程，是"怎么学会学习"，目标是让人成为能持续学新东西的人。GitHub 仓库已获 17.8K+ Stars（2026-11-12 采集时），先后获微博与知乎想法两次推荐。

## Identity（身份信息）

- Type（类型）: 开源书籍（电子书 / GitHub 开源项目）
- Organization（所属组织）: 李笑来（xiaolai）
- Role（角色）: 自学方法论读物，以编程为载体的元学习教材
- Status（状态）: 活跃开源，持续被社区推荐

## Important Facts（重要事实）

- 仓库：`https://github.com/xiaolai/the-craft-of-selfteaching`（微博帖转述的 `selfteaching/` 前缀为转述偏差，以作者仓库为准）。
- 星数：17.8K+ Stars（知乎想法 2026-11-12）；微博帖（2026-10）称 1.7 万星，星数具时效性。
- 全书核心：学不会自个儿学，前头基本没什么指望；想把长期学习磨成肌肉记忆，先揣着一点点嚼（小步持续、反复咀嚼）。
- 结构三块：为什么自学值得做 → 以 Python 为例过基础（函数、递归、测试）→ 拆难题与防注意力跑偏。
- 定位：编程只是入口不是终点，核心是"怎么学会学习"。
