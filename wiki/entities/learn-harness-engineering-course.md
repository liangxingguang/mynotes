# Learn Harness Engineering

## Overview（概览）

Walking Labs 出品的开源 Coding Agent 工程课程，教的是 Agent 的工作环境（Harness）设计：如何组织仓库、保存进度、控制任务范围、验证 Agent 是否真完成工作。

## Identity（身份信息）

- Type（类型）: 开源教学课程（GitHub 仓库）
- Organization（所属组织）: Walking Labs
- Role（角色）: Coding Agent 使用者的 Harness 工程系统教程
- Status（状态）: 已开源（据微博推荐帖；仓库当前状态未核验）

## Important Facts（重要事实）

- 规模：14 讲 + 8 个递进式动手项目。
- 提供中文资料与可复用模板。
- 动手项目环境要求：可用的 Coding Agent、Git、Node.js / Electron。
- 仓库：github.com/walkinglabs/learn-harness-engineering。
- 目标人群：已经在用 Coding Agent、想系统改善开发流程的开发者。

## Products / Projects（产品／项目）

- 课程仓库本体（walkinglabs/learn-harness-engineering）

## Relationships（关系）

- [[ep-harness|EP-Harness]]、[[aibox|AiBox]]、[[deepseek-harness|DeepSeek Harness]]：同属 Harness 工程主题——前者是面向个人的教学材料，后三者是企业/产品侧的 Harness 平台实践（同类参照）。
- [[agent-loop|Agent Loop]]：课程所教的"工作环境"对应 Prompt→Context→Harness→Loop 分层中的 Harness 层（derived-from 该概念框架，解读）。
