# NamiAgent

## Overview（概览）

NamiAgent 是一个开源 AI Agent 教程项目：零基础入门 AI Agent 的基础教程，同时也是一个能在本地跑起来的 Agent。

## Identity（身份信息）

- Type（类型）: 开源教程项目 + 本地可运行的 Agent 实现
- Organization（所属组织）: github.com/aa1143（个人开源）
- Role（角色）: AI Agent 入门教学资源
- Status（状态）: 活跃（2026-11-02 微博推荐）

## Important Facts（重要事实）

- 能力清单：读写文件、执行命令、MCP、长期记忆。
- 教学路径：从 100 行最小循环开始，一课加一个能力，最后拆解 Claude Code、Codex 等主流 Agent。
- 本地版可接 DeepSeek key；网页端左侧看每一步推理与工具调用、右侧看每次发给模型的完整上下文逐轮变长。
