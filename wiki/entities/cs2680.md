# CS2680（哈佛 AI 系统课程）

## Overview（概览）

CS2680《Modern AI Systems: Agents and System Optimizations》是哈佛 2026 秋季开设的新课，由 Juncheng Yang 主讲，哈佛 MaDSys（Measurement and Design of Systems）研究组支持。设计思路：从头到尾只跟一个 Agent 系统走，从应用层 Agent Loop 一路拆到推理服务和 GPU。5 个递进作业围绕同一系统 Mads，另有期末项目。课程主页公开大纲、幻灯片与阅读清单，对非哈佛用户也有收藏价值。

## Identity（身份信息）

- Type（类型）: 大学课程
- Organization（所属组织）: 哈佛大学（Harvard University），MaDSys 研究组
- Role（角色）: Agent 系统与推理优化系统课程（研究生级）
- Status（状态）: 活跃（2026 秋季首开，名额 80 人已满，可旁听无算力）

## Important Facts（重要事实）

- 课程全名：Modern AI Systems: Agents and System Optimizations
- 主讲：Juncheng Yang；研究组：MaDSys（Measurement and Design of Systems）
- 第一部分（LLM 与 Agent）：Claude Code 原理、多 Agent 协作、上下文管理与工具设计、多 Agent 架构、记忆与可靠性、Agent 评测、成本与性能权衡
- 第二部分（支撑 Agent 的系统）：批处理与调度、KV Cache 与前缀复用、路由与负载均衡、剪枝与量化、speculative decoding、GPU 与 kernel
- 作业系统 Mads（Modern Agent Design and Systems）五件套：Mads-Lens（观察）/ Mads-Loop（搭 Agent Loop）/ Mads-Opt（token 性价比）/ Mads-Serve（GPU 部署开源权重模型）/ Mads-Stack（端到端优化）
- 考核：无考试，期末项目；加分项每提交一个"当前 AI 解决不了的问题"加 2 分
- 授课嘉宾来自 Snowflake、Meta；阅读清单从 ReAct、MemGPT 到 vLLM、SGLang、EAGLE、GPTQ、AWQ
- 先修要求：CS61 + 至少一门研究生级系统课，熟悉 Python/PyTorch；课程不教完作业所需全部知识，拿 A 需大量课后自学与实验
- 课程主页：https://cs2680.seas.harvard.edu/
