# 微博推荐：GitHub 万星项目《自学是门手艺》——教的不是编程，是学会学习

## Overview（概览）

两篇推荐帖（微博 2026-10、知乎想法 2026-11-12）共同推荐 GitHub 开源书《自学是门手艺》（xiaolai/the-craft-of-selfteaching，李笑来著）：以 Python 为入口讲自学方法论，目标是让人成为"能持续学新东西的人"。

## Key Facts（关键事实）

- 星数：微博帖（2026-10）称 1.7 万星；知乎想法（2026-11-12）称已拿下 17.8K+ Stars（星数具时效性，以采集时为准）。
- 结构三块：为什么自学值得做 → 以 Python 为例过基础（函数、递归、测试）→ 拆难题与防注意力跑偏。
- 全书核心一句话：学不会自个儿学，前头基本没什么指望；想把长期学习磨成肌肉记忆，先揣着一点点嚼（小步持续、反复咀嚼）。
- 定位：编程只是入口不是终点，核心是"怎么学会学习"；适合想练长期学习能力的人。
- 仓库：`https://github.com/xiaolai/the-craft-of-selfteaching`（知乎想法给出作者仓库；微博帖转述的 `selfteaching/the-craft-of-selfteaching` 前缀为转述偏差，以作者仓库为准）。

## Important Claims（重要论断）

### Claim 1：自学能力本身是可教可练的手艺

以编程为载体传递元学习方法是该书的核心卖点（信源观点）。

### Claim 2：长期学习靠"一点点嚼"磨成肌肉记忆

学习无法绕过自己下功夫，小步持续、反复咀嚼是把长期学习内化为能力的方式（知乎想法观点）。
