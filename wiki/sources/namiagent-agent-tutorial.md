# 微博推荐：NamiAgent——零基础 AI Agent 本地实战教程

## Overview（概览）

微博博主「蚁工厂」推荐的 NamiAgent（仓库 github.com/aa1143/NamiAgent）：零基础入门 AI Agent 的基础教程，同时也是一个能在本地跑起来的 Agent——读写文件、执行命令、MCP、长期记忆，自带网页端看清每一步。

## Key Facts（关键事实）

- 项目：NamiAgent，仓库 `github.com/aa1143/NamiAgent`。
- 定位：零基础入门 AI Agent 的基础教程 + 可本地运行的 Agent 实现。
- 能力清单：读写文件、执行命令、MCP、长期记忆；自带网页端看清每一步。
- 教学路径：从 100 行最小循环开始，一课加一个能力，最后拆解 Claude Code、Codex 等主流 Agent。
- 本地版特色：可接 DeepSeek key；网页端左侧看它每一步怎么想、调了什么工具，右侧看每次发给模型的完整上下文一圈圈怎么变长。
- 前序：博主上次发过在线阅读版（微博链接 RoW2Zajwc）；本帖互动 转发 72 / 评论 6 / 赞 78。

## Important Claims（重要论断）

### Claim 1：100 行最小循环是入门 Agent 的可行教学路径

从最小可运行循环开始、每课加一个能力、最后拆解主流 Agent（Claude Code、Codex），是零基础理解 Agent Loop 的教学路线（信源观点）。

### Claim 2：网页端可视化推理与上下文是理解 Agent 运行的有效手段

左侧看每一步怎么想、调了什么工具，右侧看每次发给模型的完整上下文怎么变长——把不可见的 Loop 内部过程变成可见的演示（信源观点）。
