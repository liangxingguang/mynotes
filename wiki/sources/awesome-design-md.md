# 用 DESIGN.md 治 AI 生成的丑 UI：awesome-design-md 仓库

## Overview（概览）

知乎短想法推荐 GitHub 仓库 VoltAgent/awesome-design-md：沿用 Google Stitch 的 DESIGN.md 思路，用一份纯文本设计规范文件约束 AI 生成的 UI 风格。

## Key Facts（关键事实）

- 仓库收录 73 个知名网站的设计配置（Claude、Cursor、Vercel、Notion、Figma、Linear 等）。
- 用法三步：复制对应 md 到项目根目录 → 提示 AI 遵循 → 产出风格统一的 UI；无需导 Figma 或写配置。
- 想法称该仓库 GitHub 全球排名约第 150（未给出排名口径）。

## Important Claims（重要论断）

### Claim 1：AI 生成 UI 的"丑与不统一"可用一份纯文本设计规范约束

把设计规范降级为版本可控的纯文本文件，让 AI 在生成时遵循，替代设计稿传递。

## Concepts Introduced（引入的概念）

- DESIGN.md（项目根目录的纯文本 UI 设计规范文件，源自 Google Stitch 思路）

## Entities Mentioned（提及的实体）

- VoltAgent/awesome-design-md（GitHub 仓库，未单独立页）

## Implications（影响／启示）

与 CLAUDE.md/AGENTS.md 同类：把"约束 AI 行为的知识"固化为仓库内文本文件是低成本、可 review 的做法（解读）。

## Limitations（局限）

- 知乎短想法，信息量少；排名说法无出处；未评估实际生成效果。
