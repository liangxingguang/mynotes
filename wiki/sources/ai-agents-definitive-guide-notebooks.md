# 知乎想法：O'Reilly《AI Agents - The Definitive Guide》配套代码全开源

## Overview（概览）

知乎想法（作者"小理同学"，2026-10-01，68 赞同）：O'Reilly《AI Agents - The Definitive Guide》作者把整套配套代码传到 GitHub（Nicolepcx/ai-agents-the-definitive-guide），12 章 35 个 Jupyter notebook，均带 Colab 一键运行。资源指针类采集。

## Key Facts（关键事实）

- 仓库：github.com/Nicolepcx/ai-agents-the-definitive-guide，12 章 35 个 notebook。
- 内容覆盖：思维链/思维树/ReAct 模式、多 Agent 协作、记忆管理、效果评估、成本核算。
- 每个 notebook 带 Colab 一键运行按钮，无需本地 Python 环境。
- 最后一章专讲 Agent 系统威胁建模——发帖者认为这类入门内容外头少见。
- 不买书也可从第一章跑到最后一章。
