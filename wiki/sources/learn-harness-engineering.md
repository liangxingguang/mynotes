# Learn Harness Engineering：开源 Coding Agent 工程课程（微博 @黄建同学）

## Overview（概览）

微博博主「黄建同学」推荐 Walking Labs 出品的开源课程 [[learn-harness-engineering-course|Learn Harness Engineering]]：围绕 Coding Agent 的工作环境（Harness）工程展开教学。

## Key Facts（关键事实）

- 课程规模：14 讲 + 8 个递进式动手项目，提供中文资料与可复用模板。
- 主题：Agent 工作环境设计——组织仓库、保存进度、控制任务范围、验证 Agent 是否真完成工作。
- 动手项目环境要求：可用的 Coding Agent、Git、Node.js / Electron。
- 仓库地址：github.com/walkinglabs/learn-harness-engineering。
- 微博发布于 2026-10-19 23:20（北京），互动 90 转发 / 4 评论 / 77 赞。
