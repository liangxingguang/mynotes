# Pi School 官方课程主页：在 Pi 里边用边学的免费 Agent 入门课

## Overview（概览）

Pi School（pi-school.ziki.boo）官方课程主页。[[pi|Pi]] 的官方免费入门课，独特形式是"课在 Agent 里上"：除 Lesson 1（安装）在浏览器完成外，其余课程全部在 Pi 内部交互进行。

## Key Facts（关键事实）

- 官方定位：Pi 是免费开源的本地 agent harness，可读写文件、写代码、跑命令、操控其他应用；支持 15+ 模型提供商（Claude/GPT/Gemini 等）。
- 设计哲学（官方自述）：核心保持极简，不内置 sub-agents / plan mode，靠 extensions、skills、prompt templates、MCP servers 自行扩展或安装现成包。
- 上课机制：每节课页面给一段提示词贴进 Pi，Pi 当讲师带学并自动标记完成，完成状态实时同步回网页。
- 课程内容：安装配置、用 AI 写改代码、信任模型（trust model 及与其他 agent 的差异）、skills/模板/扩展、会话历史导航与分支、做网站/游戏等创意项目。
- 门槛：免费永久、无需账号、不收集个人数据；只需基本命令行能力，面向普通用户与资深开发者。
