# 给程序员推荐两个良心网站（知乎想法：systemdesign.io + AI 系统学习教程）

## Overview（概览）

知乎想法推荐两个面向程序员的免费学习网站：systemdesign.io（系统架构设计问题集）与 aiengineeringfromscratch.com（AI 系统学习教程）。单信源资源推荐，未对网站内容独立验证。

## Key Facts（关键事实）

- 信源：知乎想法 https://www.zhihu.com/pin/2098721479923975004，话题 #AI #网站推荐，采集时间 2026-11-05
- systemdesign.io 收集 50+ 常见软件系统架构设计问题（网盘、分布式消息队列、AutoComplete 服务等），每题附文章/视频参考资料
- systemdesign.io 初衷是系统架构师面试准备；作者建议现在的更好用法是交给 Agent 作为软件架构设计参考
- aiengineeringfromscratch.com 为系统学习 AI 的免费开源教程，共 20 章 542 节课，覆盖数学基础→深度学习理论→模型训练→Agent 应用→文本/视觉/语音模型
- aiengineeringfromscratch.com 提供若干 learning path 按需求挑选课时（如只想学用 AI 模型搭 Agent 应用，挑选 14 节课）
- aiengineeringfromscratch.com 免费开源，含图表、代码示例与扩展阅读

## Important Claims（重要论断）

### Claim 1：systemdesign.io 应从「面试准备」转向「给 Agent 做架构设计参考」

原文：网站初衷是给系统架构师面试做准备，作者认为现在更好的用法是把这个网站给 Agent，作为软件架构设计的参考。

这是作者的解读（解读），非既定事实。

### Claim 2：AI 学习不必全部学完，按 learning path 挑选

原文：对大多数人来说没有必要把所有内容都学完，网站设定了几个 learning path 根据需求帮选课时。
