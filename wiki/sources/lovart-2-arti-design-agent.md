# Lovart 2.0 发布：设计 Personal Agent Arti 上手体验

## Overview（概览）

产品体验文（软文性质）：Lovart 2.0（2026-10-19 上线，国内可直接用）推出设计 Personal Agent "Arti"——记忆偏好、自动调研、画布巡检、评论转修改、流程沉淀为 Skill、定时委托；作者用万圣节周边与游戏直播间两个委托实测。

## Key Facts（关键事实）

- Arti 能力面：记忆（偏好/风格/角色/工作习惯，可聊可传作品集）、自动调研报告、画布巡检（后台对照委托要求查画布，发现不对提醒、改不改由人定）、同事评论自动对应元素并交 Arti 处理成新版、一句话把流程沉淀成 Skill、定时委托（如每月节日物料）。
- "委托"模式：把一整件事交出去——要什么、有哪些限制、做到哪步停下来等人；人只管两头：开头说清需求、中间节点拍板。对比"一句一句指挥、人走活停"的旧用法。
- 实测：万圣节周边 5 分钟出首稿，两套风格（趣味扁平/中世纪）完成；直播间设成每月一次定时委托。
- "个人"目前主要体现在记忆上；"自进化技能"作者尚未体验到（用得太少）。
