# 创业点子生成与评估框架（YC）

## Definition（定义）

YC 合伙人 Jared Friedman 提出的创业点子方法论，由三部分组成：四个最常见错误（避坑清单）、评估任意点子的十问框架、生成好点子的七个配方。核心立场：爱上问题而非方案；点子是"好的起点"而非完美答案；最终验证方式只有一个——发出去。

## Why It Matters（为什么重要）

它把"找点子"从灵感事件变成可操作的流程：有数据支撑（YC 前 100 公司分析）、有评估标准（十问）、有生成方法（七配方）、有错误模式清单（SISP/焦油坑）。关键数据点：YC 前 100 公司至少 70% 的点子是自然注意到的，刻意想容易想歪。

## Core Characteristics（核心特征）

### 四大常见错误

1. **SISP（为方案找问题）**：从技术/方案出发找问题（"AI 很酷能用在哪"），找到的多是编出来的伪需求
2. **焦油坑点子（tar pit）**：围绕普遍问题、表面说得通、但有结构性难点极难解决（经典例：约朋友见面 App，二十年无人做成）
3. **扑向第一个点子**：没想过"能不能做成好生意"
4. **苦等完美点子**：世上没有完美点子，等的人最后从未创业

### 十问评估框架

Q1 创始人-市场匹配（最重要）→ Q2 市场规模（大或高增长）→ Q3 问题多痛（替代方案是"没有"最佳）→ Q4 竞争对手（多数是好事）→ Q5 自己是否想要 → Q6 最近的变化 → Q7 对标 proxy → Q8 愿做多年 → Q9 可规模化 → Q10 点子空间命中率。

### 七个生成配方（按成功率降序）

团队专长 → 亲历问题 → 自己想要的东西（最易踩焦油坑）→ 世界新变化 → 成功公司新变体 → 系统性访谈 → 坏掉的大行业；附加：找已有点子的联合创始人。

## Structure（结构）

```text
避坑（四错误） → 评估（十问） → 生成（七配方） → 验证（发出去）
辅助概念：点子空间（idea space）= 高命中率 + 创始人匹配；
         初始点子不对也能在肥沃空间内漂移（Fivetran）
```

## How It Works（运作方式）

- 反直觉三件事让点子"看起来差实际变好"：启动很难（Schlep Blindness，Stripe）、无聊领域（Gusto）、有竞争对手（Dropbox 第 20 家云存储）——多数人躲开，机会留在桌上
- 配方 1+2 的操作说明：把每份工作/实习/人生经历逐个过一遍，问"你遇到过哪些问题？学到哪些别人不知道的东西？哪些问题是你处在特殊位置才看得到的？"
- 不打算马上创业的长线做法：成为前沿专家 / 去创业公司工作 / 做觉得有意思的东西（Replit 路径）

### Distinctions（区分）

- 与一般"头脑风暴找点子"：本框架明确反对刻意空想为主路径（70% 好点子自然注意到），刻意想需借配方约束（专长/亲历/变化/对标）才有效。
