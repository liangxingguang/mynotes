# 深度思考五工具（澄清-拆解-追问-反证-逆向）

## Definition（定义）

YouCore 提出的一套按固定顺序使用的结构化思考流程：澄清 → 拆解 → 追问 → 反证 →（必要时）逆向。前四步逐步收敛问题到一个可下手、经得起检验的发力点；第五步逆向是发散出口，仅在前四步走不通时启用。

## Why It Matters（为什么重要）

它针对的具体病症是「认知闭合需要」（Kruglanski）：面对不确定时人迫切想要一个明确答案，一旦有了答案就固着不改（如把晋升落选归因为"不够努力"）。五工具的价值在于用流程强制"下结论之前再多想一步"，把模糊抱怨转成可验证、可行动的问题。

## Core Characteristics（核心特征）

1. **澄清**：把不可验证的表述换成可验证的话（量化时长/产出、明确比较对象）——"澄清的问题已解决一半"
2. **拆解**：用 5W2H 一次问全防漏项；Why 问目的，目的不同解法完全不同（"要 P7" vs "想主导成一件事"）
3. **追问**：追根本原因，终点是"你的手能够到的那一层"，不是"最深的原因"——追到动不了的层面只会带来无力感
4. **反证**：用演绎推理检验因果链的充分性与必要性；任何"因为 X 所以 Y"都藏着"只要 X 就会 Y"的隐含假设
5. **逆向**：发散出口，三种类型——缺点逆向（利用缺点）、反转型（反转属性）、转换型（换对象不换结果）

## Structure（结构）

```text
说不清 → 澄清
说不全 → 拆解（5W2H）
找不到根 → 追问（到可及层为止）
不确定 → 反证（充分性+必要性）
没路了 → 逆向（三种类型，前置四步完成才有效）
```

## How It Works（运作方式）

原文以"P6 加班全组第一却两次晋升落选"案例完整演示：澄清（量化出差距项是"独立发起项目 1/5 分"而非努力）→ 拆解（Why 重定义目标为"主导成一件事"）→ 追问（根因是"把交代的事做好机会自然来"的认知）→ 反证（"做出独立项目就会晋升"既不充分也不绝对必要）→ 逆向（转换型：换公司不换目标，最终跳槽升一级）。
