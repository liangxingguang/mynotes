## 何时使用

- 用户就某个概念、实体、主题、决策询问"知识库里怎么说的"
- 需要基于已编译知识回答问题，而不是重新抓取网页

## 第 0 步（强制前置）

先读取 `AGENTS.md`（尤其第 11-12 节查询与回答契约、附录 A 权限边界）。

## 检索顺序

1. `wiki/index.md` — 定位候选页面
2. 命中页面的 Wiki 页面（`[[wikilink]]` 直接打开）
3. 沿 `related` 与被链接页面扩展
4. **覆盖不足时**才读 `raw/` 原始信源
5. 仅在被明确允许或确有必要时才做外部检索

## 回答契约

- 区分并标注：已确立的知识 / 综合归纳 / 推断 / 不确定性 / 矛盾 / 缺失信息
- 引用时用 `[[页面名]]` 指向真实存在的 Wiki 页面
- 承重性事实须给出 `raw/` 溯源
- **绝不把低置信度的综合归纳当作已验证事实呈现**

## 覆盖不足时（关键）

明确声明「Wiki 中没有足够的已编译知识」，并说明：已检索了哪些页面、缺什么、可回退到哪些 `raw/` 信源提供线索。不得凭记忆或想象补全。

## 写入边界

- 只读 `wiki/`；**唯一例外**是可向 `wiki/log.md` 追加一行 query 记录（不得改写历史条目）
- 不得创建或修改任何 Wiki 页面、不得改 `raw/`、不得改 `wiki/index.md`

## 输出

- 直接作答（IM 精简，≤10 条要点）
- 附来源页面链接与 raw 溯源
- 矛盾或未确立之处单独标注

## 权限边界（Query 行）

| 能力 | 是否允许 |
|------|------|
| 读取 Raw | ✅ |
| 修改 Raw | ❌ |
| 创建 Wiki | ❌ |
| 修改 Wiki | ❌ |
| 回答问题 | ✅ |
| 修改 Index | ❌ |
| 修改 Log | ✅（仅追加 query 记录） |
| 语义判断 | ✅ |
| 删除知识 | ❌ |
| Archive | ❌ |

完整边界表见 `AGENTS.md` 附录 A。
