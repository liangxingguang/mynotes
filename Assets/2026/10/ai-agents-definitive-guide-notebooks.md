# 知乎想法：《AI Agents - The Definitive Guide》配套代码开源

> 作者：小理同学（编辑于 2026-10-01，IP 属地山东，68 赞同 / 334 喜欢）

Agent 开发者注意了，这波白嫖机会错过真得拍大腿❗

O'Reilly 那本《AI Agents - The Definitive Guide》口碑一直在线，作者索性把整套配套代码都传到了 GitHub，12 个章节搭 35 个 Jupyter notebook，思维链、思维树、ReAct 模式这些基础功夫，多 Agent 协作，再加上记忆管理、效果评估、成本核算这些只有上生产才会踩的坑，全都囊括进去了。

每个 notebook 都带 Colab 一键运行按钮，浏览器点开就跑，本地 Python 环境压根不用装，懒人听了直呼舒服。

我翻了下目录，最后一章专门聊 Agent 系统威胁建模，这类入门内容外头基本找不到，光把这一章啃透就值回票价。

书没买也没关系，代码照样能从第一章跑到最后一章。
