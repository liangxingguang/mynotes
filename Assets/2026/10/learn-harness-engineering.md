## 正文

Walking Labs 的 Learn Harness Engineering 是一套开源 Coding Agent 工程课程，包含 14 讲、8 个递进项目，并提供中文资料与可复用模板。

课程围绕 Agent 的工作环境展开：如何组织仓库、保存进度、控制任务范围，以及验证它是否真的完成了工作。适合已经在用 Coding Agent、想系统改善开发流程的人。动手项目需要准备可用的 Coding Agent、Git，以及 Node.js / Electron 环境。

访问：github.com/walkinglabs/learn-harness-engineering
