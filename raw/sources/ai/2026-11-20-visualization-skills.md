# 5个能让内容信息更易懂的可视化skill

分享一组我平时工作中经常用来解释概念的skills。  
1.skill：diagram-design  
38 种架构/流程/数据/战略图表，输出自包含 HTML+SVG，可品牌适配+动效。

2.skill：ian-xiaohei-illustrations  
把中文文章里的判断、流程、状态和隐喻，变成白底、手绘、怪诞但清爽的正文配图。默认视觉 IP 是小黑（可让AI把Skill中的主人公改成你想要的）

3.skill：guizang-material-illustration  
归藏素材插画技能：为文章生成带字解释图、图表美化与参考配图，适配 Claude Code / Codex（可让 AI 把skill适配到其他主流AI智能体上跑通）

4.skill：smart-illustrator  
智能文章插图 Skill，三引擎系统（Gemini 创意视觉+Excalidraw 手绘图表+Mermaid 结构化图表），自动根据内容类型选择引擎。可让 AI 把skill适配到其他主流AI智能体上跑通。

5.skill：concept-infographic-engine  
一个对标 GPT-Image2 上 Template 库的 Infographic Engine 风格的skill。  
当用户需要解释概念时，只需把内容信息发给智能体，调用这个skill，它就能主动从内容中提取关键的信息，再投入到生成的图片当中去。
