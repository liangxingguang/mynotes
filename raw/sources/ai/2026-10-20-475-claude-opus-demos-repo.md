# GitHub 仓库收录 475 个 Claude Opus 5.5 生成的视频演示

这他妈的太牛逼了

一个 GitHub 仓库中用 CLAUDE OPUS 5.5 构建的 475 个视频演示

动态图形、解说视频、3D 场景，甚至游戏，全都用 HTML、Canvas、SVG 和 Three.js 制作。

最疯狂的部分？每个演示都附带其原始提示和来源帖子，所以你可以挑选任何一个，自己试着重现。

475 个示例供你学习和实验。
