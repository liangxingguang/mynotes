# 今天分享 6 本 GitHub 开源 AI 书籍

> 来源：知乎想法（Pin）| 抓取方式：浏览器渲染 | 抓取时间：2026-11-04

今天分享 6 本 GitHub 开源 AI 书籍，全部免费，部分附带代码与视频。碎片化内容只能认识名词，书籍能帮你理清知识之间的关联。

01《神经网络与深度学习》

复旦邱锡鹏老师的蒲公英书，深度学习经典中文入门教材，GitHub 1.9 万星。开源第二版与通识版，均可免费下载

地址：https://github.com/nndl/nndl

02《Agentic Design Patterns》中文版

谷歌工程师原作，整理 21 个 Agent 设计模式，xindoo 完成全文翻译，8100 多星。覆盖提示链、工具调用、多 Agent 协作，还有安全与落地评估。

地址：https://github.com/xindoo/agentic-design-patterns

03《深入理解 AI Agent》 李博杰著

本次书单星数最高，5.4 万星。仓库含全书 PDF 和配套实验代码。核心公式：Agent = 大模型 + 上下文 + 工具。重点讲解工程能力，包含记忆、工具调用、多智能体协作。

地址：https://github.com/bojieli/ai-agent-book

04《深入理解 AI Infra》 李博杰的姊妹篇

讲解大模型运行资源估算，算力、显存、带宽、电费如何影响延迟与成本，适合 AI 产品人做成本测算。

地址：https://github.com/bojieli/ai-infra-book

05《强化学习的数学原理》

深挖强化学习底层数学逻辑，需要概率论、线代基础。

地址：https://github.com/MathFoundationRL/Book-Mathematical-Foundation-of-Reinforcement-Learning

06《Hands-On Modern RL》

WalkingLab 开源实战教程，4500 多星，和上面这本互补。从倒立摆案例入门，延伸到 Agent 实战，每章附带可运行 Python 代码。

地址：https://github.com/walkinglabs/hands-on-modern-rl

阅读选择指南：

只想看懂 AI 基础：《神经网络与深度学习》通识版
搭建 Agent：先《Agentic Design Patterns》，再《深入理解 AI Agent》
AI 产品成本测算：《深入理解 AI Infra》
深耕强化学习：数学原理搭配实战教程

工具和教程会过时，但底层原理相对稳定。

花一个月读完一本书，比长期刷碎片化教程收获更大。
