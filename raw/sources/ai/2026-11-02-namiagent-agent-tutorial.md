Agent教程： NamiAgent
地址：github.com/aa1143/NamiAgent
零基础入门 AI Agent 的基础教程。同时也是一个能在本地跑起来的 Agent：读写文件、执行命令、MCP、长期记忆，自带网页端看清每一步。从 100 行最小循环开始，一课加一个能力，最后拆解 Claude Code、Codex 等主流 Agent

上次发过它的在线阅读版：网页链接（https://weibo.com/2194035935/RoW2Zajwc）

- 左边看它每一步怎么想、调了什么工具
