# 分享一套超赞的AI知识库搭建方法，让沉睡的数据变成可复用的经验

> 摘要：公众号「咘噜鸭」讲用 WorkBuddy + ima + Wiki 的思路搭建可复用知识库。出发点是 Karpathy 的主张：不要把 LLM 当搜索引擎，而是让它像程序员写代码一样持续维护一个 Markdown 知识库。文章给出 7 步搭建流程、三个文件夹的分工，以及一份让 AI 真能连得上页面的维护约定。

## 核心要点

- **核心思路（Karpathy）**：不要把 LLM 当搜索引擎用，而是让它像程序员写代码一样，帮你持续维护一个 Markdown 知识库。**你负责找资料、提好问题，LLM 负责总结、交叉引用、分类整理、保持一致性**——你在 Obsidian 里浏览，LLM 在后台编辑，知识库像滚雪球一样越滚越大。
- **三件套分工**：WorkBuddy 负责读取资料、核对数据、分析问题、整理复盘、整合信息；ima 负责保存原始资料、经验档案和任务结果；Wiki 负责按主题给相关内容建立交叉索引。整个流程一句话：**资料归集 → 分析复盘 → 更新知识库 → 下一次调用 → 行动执行 → 记录反馈**。
- **三个文件夹各管一件事**：`01_原始资料`（数据表、项目文档、会议纪要、过程记录、沟通反馈、阶段总结、规则与模板）；`02_经验档案`（背景画像、知识库导航、主题档案、方法页、常见问题、固定流程、指标口径）；`03_任务结果`（分析报告、阶段复盘、行动清单、周期总结、知识库检查报告）。
- **五类场景只是装进去的内容不同**：电商直播（直播后台数据/投流记录/商品资料/现场记录 → 成交下滑怎么查、投流怎么复盘、讲解与链接如何衔接）、内容创作、客户服务、项目执行、个人学习，都可以按同一套思路搭。
- **七步流程**：① 把 ima 接进 WorkBuddy（找到 ima 知识库入口并授权）；② 建好三个文件夹；③ 先放几份资料把流程跑通，别一次全倒进去；④ 用一段提示词让 WorkBuddy 生成《001_背景画像》《002_知识库导航》《003_知识库维护约定》并上传到 `02_经验档案`；⑤ 让它干一次活（例："我想复盘 9月10日 的直播情况，和 9月3日 那场做个对比"）；⑥ 把验证过的经验更新回知识库（"请把复盘结果更新进知识库"）；⑦ 用 WorkBuddy 设月度定时任务做知识库体检。
- **一个容易卡住的点**：ima 虽然和 WorkBuddy 连着，**但不能直接在 WorkBuddy 里给 ima 建立文件夹**，得用 ima 自带的 Agent 创建或手动建。
- **最关键的一句**：这种"能找到"**不是靠 ima 自动交叉索引，而是靠《003_知识库维护约定》里的规则维护出来的**——页面互相写清《完整文件名》、导航里登记入口、双向引用两边都写。**AI 不会自动帮你连，约定才让它连得上。**
- 闭环：执行新任务前先调用知识库、并和 WorkBuddy 说清楚任务细节 → 照它给的建议执行 → 任务完成后把结果反馈回去。资料越攒越多，重复、过期、遗漏也会变多，**每月检查一次就是给知识库做体检**。

大家好，我是咘噜鸭。

前段时间 Karpathy 提出了用 LLM 管理个人知识库的一个核心思路：**不要把 LLM 当搜索引擎用，而是让它像程序员写代码一样，帮你持续维护一个 Markdown 知识库。** 你负责找资料、提好问题，LLM 负责所有的脏活累活——总结、交叉引用、分类整理、保持一致性。你在 Obsidian 里浏览，LLM 在后台编辑，知识库就像滚雪球一样越滚越大。

> 一个精心策划的知识存储，文档之间的关联和文档本身一样有价值。

但是，对于不懂技术的用户，用 Obsidian + LLM 搭建知识库是很困难的。于是可以在 **WorkBuddy + ima** 的基础上，加入 **Wiki 的核心思路**，搭建一套能让文档交叉索引、让知识复利增长的知识库。

- **WorkBuddy** 负责读取资料、核对数据、分析问题、整理复盘和整合信息；
- **ima** 负责保存原始资料、经验档案和任务结果；
- **Wiki** 负责按主题给相关内容建立交叉索引。

电商直播、内容创作、客户服务、项目执行、个人学习等等，都可以按同一套思路搭建知识库。下面用真实的电商直播场景展示具体搭建方法。

### 第一步：把 ima 接进 WorkBuddy

先打开 WorkBuddy，找到 ima 知识库入口，点击 ima，按界面提示完成授权。到这里，ima 和 WorkBuddy 就算彻底打通了。

### 第二步：在知识库中建好三个文件夹

打开 ima，新建一个知识库，可以叫《经验复用知识库》（已有合适的也可以继续使用），然后在里面建三个文件夹：`01_原始资料`、`02_经验档案`、`03_任务结果`。

| 文件夹 | 放哪些文件 |
|---|---|
| 01_原始资料 | 数据表、项目文档、会议纪要、过程记录、沟通反馈、阶段总结、规则与模板 |
| 02_经验档案 | 背景画像、知识库导航、主题档案、方法页、常见问题、固定流程、指标口径 |
| 03_任务结果 | 分析报告、阶段复盘、行动清单、周期总结、知识库检查报告 |

不同场景只是装进去的内容不同：

| 使用场景 | 原始资料 | 沉淀的经验 |
|---|---|---|
| 电商直播 | 直播后台数据、投流记录、商品资料、现场记录 | 成交下滑怎么查、投流怎么复盘、讲解与链接如何衔接 |
| 内容创作 | 选题记录、内容数据、修改稿、读者反馈 | 哪类选题值得复用、修改了什么、后续表现怎样 |
| 客户服务 | 问题记录、处理过程、回访结果、规则说明 | 高频问题怎么处理、哪些方法适用于哪些情况 |
| 项目执行 | 任务表、会议纪要、排期、验收反馈 | 需求变更怎么查、延期怎么处理、协作如何衔接 |
| 个人学习 | 练习记录、错题、阶段测试、学习总结 | 哪类错误反复出现、什么方法有效、下一步怎么练 |

> 注意：ima 虽然和 WorkBuddy 连着，但是**不能直接在 WorkBuddy 里给 ima 建立文件夹**。可以用 ima 自带的 Agent 来创建，或者在 ima 中手动创建。

### 第三步：放进第一批能用起来的资料

第一次建库，别急着把所有文件全倒进去，先放入几个资料，把整个流程跑通再说。可以直接打开 ima，点击选好知识库之后，点击右上角的加号导入内容。看文章时也可以顺手点击右上角的三个点，在"更多打开方式"中选择 ima，再点击"加入 ima 知识库"。

### 第四步：让 WorkBuddy 初始化经验档案

现在 `01_原始资料` 里已经有各种资料了，但 WorkBuddy 此时并不知道你是谁、主要做什么、这些资料跟你有什么关系、想解决什么问题、有什么工作习惯。回到 WorkBuddy，把上传到《01_原始资料》中的资料添加到对话任务，然后把下面这段提示词发给它：

```
我正在搭建一个长期使用的经验知识库，希望以后分析数据、处理问题、复盘工作时，都能用上以前积累的资料和经验。
```

回答时不用写长篇介绍，把当前做的事和最头疼的问题说清楚就好。收到文件后，看看 AI 有没有正确理解目标；确定没问题了，点击更多 → 上传到云端 → ima，把这三份文件放进《02_经验档案》文件夹。

- 《001_背景画像.md》让 AI 了解你的情况；
- 《002_知识库导航.md》指引 AI 找到做事需要的资料；
- 《003_知识库维护约定.md》交代了知识库维护规则。

### 第五步：让知识库干一次活

初始化完成后，知识库有了雏形，接着就让它干一次活。只有真正用起来，才能把数据和经验变成持久的、可复利增长的资产。于是把下面这段提示词发给 WorkBuddy：

```
我想复盘9月10日的直播情况，和9月3日那场做个对比。
```

这个时候 WorkBuddy 掌握了背景信息、运营数据、历史经验，给出的结果就不一样了——不再是通用知识内容，而是针对性的、精准分析的回复。

### 第六步：把复盘结果更新进知识库

这一步是持续、增量构建和维护知识库的关键步骤。要做的是告诉 WorkBuddy，把验证过的经验更新进知识库，提示词是这样的：

```
请把复盘结果更新进知识库。
```

一个结构化的、互相链接的知识库就建立起来了：**报告按任务保存，Wiki 按主题维护。** 从《商品档案》，能找到《直播成交下滑怎么查》，也能回到 9月10日 那场复盘，看看当时为什么这样判断。

> 这种"能找到"不是靠 ima 自动交叉索引，而是靠《003_知识库维护约定》里的规则维护出来的：页面互相写清《完整文件名》、导航里登记入口、双向引用两边都写。**AI 不会自动帮你连，约定才让它连得上。**

下一次执行新任务前，先调用知识库，并和 WorkBuddy 说清楚任务细节；然后照着 WorkBuddy 给出的建议执行新任务；任务完成后，再把结果反馈给 WorkBuddy。循环就这样滚动起来了。

### 第七步：定期给知识库做检查

资料越攒越多，重复、过期和遗漏也会变多。**每月检查一次，就是给知识库做体检。** 在《03_任务结果》下建一个《知识库体检》子文件夹，然后用 WorkBuddy 设一个定时任务，提示词如下：

```
我想每月1日上午9点检查一次ima"经验复用知识库"。请帮我设置这个月度定时任务。
```

很快定时任务就设置好了，每月 1 号上午 9 点定时自动执行知识库检查。

### 收尾

刚开始，它可能只是几个文件夹。但半年、一年以后，里面装的就不只是资料了，还有你的判断、经验、踩过的坑，以及真正验证过的方法。每一次探索、每一次提问，都能让知识库更懂你，积累的经验也更丰富。散乱的信息被编译成结构化的知识网络，同时这个网络又随着使用不断扩展——**这就是复利的力量。**
