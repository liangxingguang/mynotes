# 给程序员推荐两个良心网站（知乎想法）

> 推荐两个免费良心网站：① systemdesign.io 收集 50+ 常见软件系统架构设计问题与解答（网盘、分布式消息队列、AutoComplete 等），原为系统架构师面试准备，作者认为更适合作为给 Agent 做软件架构设计的参考；② aiengineeringfromscratch.com 系统学习 AI 的免费开源教程，20 章 542 节课，覆盖数学基础到模型训练再到 Agent 应用与多模态，并提供按需求挑选的 learning path。

## 核心要点

1. **systemdesign.io**：收集 50+ 常见软件系统架构设计问题（如何设计网盘 / 分布式消息队列 / AutoComplete 服务等），每个问题附文章、视频等参考资料
2. 原用途是系统架构师面试准备；作者建议现在的更好用法是**把这个网站给 Agent，作为软件架构设计的参考**
3. **aiengineeringfromscratch.com**：系统学习 AI 的免费开源教程，从数学基础、深度学习理论到模型训练、Agent 应用，再到文本 / 视觉 / 语音模型，无所不包
4. 共 20 章 542 节课；提供几个 learning path 按需求挑选课时（如只想学用 AI 模型搭 Agent 应用，选 14 节课即可）
5. 免费开源，含丰富图表、代码示例与扩展阅读，适合制订「每日一课」计划
