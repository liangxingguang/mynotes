# 从 0 到 1 拆解 Claude Skills：一次构建，永久生效

> Claude Skills 实战指南：Skill 是把你的判断、偏好、标准压进一个 .md 文件的可复用资产。四步构建 + 七个提质动作 + 2.0 三大升级 + 七种已验证类型，半小时换以后每次省十分钟。

## 核心要点

- **本质**：Skill 不是提示词，是资产——把重复告诉 Claude 的规矩固化成 Markdown 文件，一句话唤醒。核心原则：任何重复说过三遍的事都值得建成 Skill。
- **四步构建**：启用官方 Skill-Creator → 结构化提示词描述需求 → Copy to Skills 并本地备份 → My Skills 一句话调用。
- **七个提质动作**：反向提问让 Claude 列需求清单；反向发现未知重复场景；把现有对话直接转成 Skill（最被低估）；贴真实范例胜过百条规则；三轮迭代；结尾加 3~5 条自查清单；手动通读全文。
- **2.0 升级**：内置断言评估（激活/不激活双跑打分）、A/B 测试、触发词自动优化——从凭感觉到有依据。
- **七种已验证类型**：品牌音调、PDF 生成、文件摘要、ELI5、求职、学习、健身。
- 解决的不只是效率，更是**一致性**：每次输出气质统一，像同一个人的手笔。
- 安全提示：只从可信创作者处下载 Skill，未审核文件有执行代码风险。
