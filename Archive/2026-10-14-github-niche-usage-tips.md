# 三个小众但实用的 GitHub 用法（zread / Deepwiki / gitingest）

> 博主分享了三个借助 AI 快速读懂 GitHub 仓库的小众工具：zread 把项目变成中文知识库，Deepwiki 直接向 AI 提问定位代码，gitingest 把仓库打包成 AI 可读文本。

## 核心要点

1. **zread**：把 GitHub 项目变成中文知识库，以目录式结构快速读懂项目全貌。
2. **Deepwiki**：直接向 AI 提问，帮助定位代码位置、解释调用关系。
3. **gitingest**：把整个仓库打包成 AI 能读的文本，喂给自己的 AI 工具使用。
