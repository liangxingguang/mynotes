# 用 DESIGN.md 治 AI 生成的丑 UI：awesome-design-md 仓库

> 知乎想法推荐 GitHub 仓库 VoltAgent/awesome-design-md：沿用 Google Stitch 的 DESIGN.md 思路，用一份纯文本设计规范文件约束 AI 生成的 UI 风格。仓库收录 73 个知名网站（Claude、Cursor、Vercel、Notion、Figma、Linear 等）的设计配置，复制对应 md 到项目根目录并提示 AI 遵循即可，无需导 Figma 或写配置。

## 核心要点

- **解决的问题**：AI 写代码已不稀奇，但生成的 UI 普遍丑、风格不统一。
- **做法**：项目根目录放一份 DESIGN.md（纯文本设计规范），AI 即按该风格产出界面。
- **仓库内容**：73 个知名网站的设计配置，含 Claude、Cursor、Vercel、Notion、Figma、Linear 等。
- **三步使用**：复制一个 md 进项目 → 告诉 AI 照此风格 → 产出风格统一的 UI。
- **热度**：想法称该仓库 GitHub 全球排名约第 150。
- **仓库地址**：https://github.com/VoltAgent/awesome-design-md
