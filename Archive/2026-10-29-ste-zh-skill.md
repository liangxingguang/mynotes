# ste-zh：简化技术中文规范 Skill

> 蚁工厂发布 `ste-zh`：一个面向 AI Agent 的任务汇报规范 skill。借鉴航空与工业界的 ASD-STE100（简化技术英语）原则，约束 Agent 用清晰、严密、无歧义的中文汇报工作结果。开源在 GitHub，微博互动 57 转 / 87 赞。

## 核心要点

- **是什么**：一份 Agent Skill，规范 Agent 汇报工作结果时的中文表达，对标工业界 ASD-STE100（Simplified Technical English）的严谨写作原则。
- **解决什么**：Agent 汇报常含糊、有歧义；用受控语言（controlled language）思路约束措辞，让结果描述清晰、严密、可核对。
- **地址**：https://github.com/dualface/ste-zh
- **社区反馈**：评论中多人 @印象笔记/@Notion 收藏，有用户反馈"用了，不错"。
- **关联**：与 [[2026-10-28-uncle-bob-ub-mode-skill|ub-mode]] 同属"用 Skill 约束 Agent 行为"的思路——一个管汇报语言，一个管开发纪律。
