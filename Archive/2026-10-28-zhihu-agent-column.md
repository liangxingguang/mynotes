# 知乎专栏《Agent》：从理论到手写 harness 的 10 篇系列教程

> 一套循序渐进的 LLM Agent 系列教程：从经典智能体理论与 agent loop 五阶段，到模型/harness 选型、手写最小 agent、把真实后台 REST API 变成工具，再到工具工程的认证/错误分级/确认闸门与全谱系安全边界。

## 核心要点

- **Part 1 打开黑盒**（1-2 篇）：Agent 是什么、工具调用长什么样、经典五类智能体与 PMTA 坐标系。
- **agent loop 与上下文**（3）：loop 五阶段、harness 基础设施、上下文管理与停止条件。
- **选型**（4-5）：通用 vs 推理模型、国内三家接入；harness 框架选型直接给结论。
- **手写闭环**（6-8）：三种 LLM 调用姿势 → 手写最小 agent（M1）→ 真实 REST 接口变工具（M2）。
- **工具工程化**（9-10）：token 重登、错误分层喂回、危险操作确认与审计；工具全谱系风险与参数注入防线。
