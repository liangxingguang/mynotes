> **摘要**：作者分享工作中常用的 5 个"解释概念"可视化 Skill：①diagram-design——38 种架构/流程/数据/战略图表，输出自包含 HTML+SVG，可品牌适配加动效；②ian-xiaohei-illustrations——把中文文章里的判断、流程、状态和隐喻转成白底手绘、怪诞但清爽的正文配图，默认视觉 IP"小黑"可自定义；③guizang-material-illustrations——归藏素材插画技能，生成带字解释图、图表美化与参考配图，适配 Claude Code/Codex 并可改到其他智能体；④smart-illustrator——三引擎系统（Gemini 创意视觉 + Excalidraw 手绘图表 + Mermaid 结构化图表），按内容类型自动选引擎；⑤concept-infographic-engine——对标 GPT-Image2 Template 库的 Infographic Engine 风格，把内容发给智能体调用即自动提取关键信息投进生成图片。

## 核心要点

- **用途**：解释概念、让内容信息更易懂的可视化 Skill 合集，适合在 Claude Code / Codex 等智能体中使用（多个 Skill 注明可让 AI 适配到其他主流智能体跑通）。
- **diagram-design**：38 种架构/流程/数据/战略图表，输出自包含 HTML+SVG，支持品牌适配与动效。
- **ian-xiaohei-illustrations**：将中文文章中的判断、流程、状态和隐喻转为白底、手绘、怪诞但清爽的正文配图；默认视觉 IP 是"小黑"，可让 AI 把 Skill 中主人公改成自己想要的形象。
- **guizang-material-illustrations**：归藏素材插画技能，为文章生成带字解释图、图表美化与参考配图；适配 Claude Code / Codex，可适配其他主流智能体。
- **smart-illustrator**：智能文章插图 Skill，三引擎系统——Gemini 创意视觉 + Excalidraw 手绘图表 + Mermaid 结构化图表，自动根据内容类型选择引擎；同样可适配其他智能体。
- **concept-infographic-engine**：对标 GPT-Image2 Template 库的 Infographic Engine 风格 Skill；解释概念时把内容信息发给智能体并调用该 Skill，它会主动从内容中提取关键信息再投入到生成图片中。
