# Phaser——比CyclicBarrier更灵活的同步屏障

> Phaser（JDK 7）是 CountDownLatch 与 CyclicBarrier 的"完全体"：可重用、参与方动态增减、支持分层与分阶段。文章剖析其核心设计——用一个 volatile long 的位布局（unarrived/parties/phase/终止位）编码全部状态，一次 CAS 完成"到达检查+阶段推进"，并讲解树形分层如何分散大规模 CAS 竞争。

## 核心要点

- 一个 64 位 state 编码 unarrived、parties、phase 和终止位，全程 CAS 无锁，单次 CAS 保证一致性
- 三个 arrive 变体：arrive() 不等待、arriveAndAwaitAdvance() 等到齐、arriveAndDeregister() 到达并退出，支持动态增减
- 分层（Tiering）：子 Phaser 各自管理线程，到齐后作为单个 party 向父报告，解决数万线程下的缓存一致性与 CAS 竞争
- 单层最多 65535 个 party；所有方 deregister 后默认 onAdvance 返回 true 自动终止
- arriveAndAwaitAdvance 不响应中断，可中断需拆成 arrive() + awaitAdvanceInterruptibly()
- 与 ForkJoinPool 深度协作：等待的 worker 线程会转去执行其他任务而非纯自旋
