# 全网硬核大模型应用开发（Agent、RAG）学习路线+配套资源，在 GitHub 开源

> 作者将多年大模型技术文章整理为开源仓库 `youngyangyang04/llm-master`，定位"程序员的大模型全栈学习路线"，含 172 个 Markdown 文件、150+ 篇中文教程，按六阶段组织，每阶段配可交付项目，并连带面试路线，形成知识—项目—简历—面试闭环。

## 核心要点

- **仓库定位**：https://github.com/youngyangyang04/llm-master，目前全网较完整、面向程序员的大模型应用开发学习路线，持续更新。
- **六阶段路线**（按知识依赖排序，每阶段标注完成标志）：
  1. 全局认知：岗位、术语、技术版图
  2. 模型调用：Prompt、流式输出、结构化输出、Function Calling
  3. RAG：切片、Embedding、检索、Rerank、引用、评估
  4. Agent：工具、状态、规划、记忆、权限、失败恢复
  5. 生产工程：部署、缓存、量化、压测、监控、容量规划
  6. 原理与面试：Transformer 原理 + 项目表达
- **覆盖范围**：基础入门、应用开发、RAG、Agent、微调（SFT/RLHF/DPO/LoRA）、部署性能（vLLM/SGLang/KV Cache/量化）、Transformer（含手写实现）、AI 编程（Claude Code/MCP/Skills）、求职面试。
- **索引体系**：除路线外有全量资料索引与专题索引（docs/README.md），可当课程从头学，也可当手册按问题查。
- **可交付项目**：流式 AI 应用、含混合检索+评测集的企业知识库、可追踪可恢复的工具型 Agent、生产化服务（限流/缓存/监控/P99/TTFT）。
- **使用建议**：零基础从 roadmap 六阶段起步；有 API 经验直接进 RAG/Agent 专题边看边做；求职从面试路线切入，练"业务—选型—设计—评估—优化"表达。
