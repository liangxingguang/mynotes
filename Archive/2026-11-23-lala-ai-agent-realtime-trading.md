# AI Agent 如何进入实时交易系统：货拉拉的三个实践与一套工程方法论

> 货拉拉技术总监亓隆基分享 Agent 进入实时交易系统的生产实践：核心判断是"用 Agent 拓展系统能力边界，而非重做已有系统"。基于意图交易（AI 下单）、持续撮合（AI 撮合）、策略执行（AI 运营）三个已上线场景，提出 Agent 生产化四层模型——模型决定起点，Harness 决定下限，Dual Loop 决定方向，业务知识决定上限。

## 核心要点

- **价值边界**：引入 Agent 须满足新增能力、新增结果、成本可覆盖三标准；不用 Agent 就能解决的事不引入。边界内（ML 预测、运筹、交易系统）由成熟系统承担，边界外（理解、规划、协调等开放式工作）才交给 Agent。
- **意图交易**：用户表达意图、Agent 理解组织、交易系统提供权威事实；靠确定边界、结构化订单草稿、确定性护栏让模型"只在值得不确定处不确定"；意图识别 99%、选车正确率 93%、下单时长缩短 25%。
- **持续撮合**：从一次性推荐走向围绕目标的持续服务（Delegation），Observe→Decide→Act→Feedback→Replan 闭环并设终止条件；Multi-Agent 划小闭环，ML/OR/规则守硬约束，Agent 把离散决策组织成连续行动；配对率 +12%、ROI 为人工 4 倍。
- **策略执行**：人定目标与授权，Agent 拆解调用工具，系统执行动作；所有业务动作走标准 Tool，按执行/异常/建议/决策分层放权，越往决策端越谨慎；33+ 运营 Agent、执行效率 +80%、操作失误降至 0。
- **四层模型**：模型（起点，大家同起点）；Harness（下限，帮模型的可删除、守业务的必写代码，判定法"假设模型完美是否仍需"）；Dual Loop（方向，内环做对事、外环定正确事，业务归因定义 Badcase，LLM-as-Judge 需人工校准）；业务知识（上限，按确定性分流：确定知识进代码、"什么是好"进评测、打法进策略）。

## 正文

**引言**：行业让 Agent 完成任务投入巨大，但"Token 消耗了这么多，创造了什么业务价值"越来越难回答。货拉拉的判断：用 Agent 拓展系统能力边界，而非重做已有能力。

**一、价值不在重做已有系统**：Agent 应用边界已从提效、辅助移到业务执行、直接参与交易，越往后价值越高、风险越大（幻觉与错误变成真实损失）。引入 Agent 的三标准为新增能力、新增结果、成本可覆盖。边界内由 ML、运筹、业务规则、交易履约系统承担；边界外的理解、规划、协调等开放式工作才交给 Agent，把原只有人能完成的工作转化为系统可持续完成目标的能力。

**二、意图交易**：让用户不必先成为半个物流专家，直接意图下单。分工为用户表达并确认、Agent 理解组织追问、交易系统提供权威事实（地址二次确认、车型因城而异、价格来自计价系统）。可靠完成交易三方面：先确定边界（ToC 响应时间不妥协，按难度选模型）、结构化订单草稿（信息变化重确认而非从历史推断）、确定性护栏（事实由系统确定、确认后执行、受权限状态机幂等约束）。专业选车由 LLM 识别品类追问、装载规则写成代码约束、对照车型库排除，做到理解交模型、约束交代码、事实交车型库。

**三、持续撮合**：一次匹配失败后系统仍能朝目标推进。司机侧从一次性推荐走向围绕目标的持续服务（Delegation）；订单侧对长尾订单以成单为目标持续推进，闭环 Observe→Decide→Act→Feedback→Replan，并在成功匹配、状态变化、时效到期、风险触发时终止——没有终止条件的持续行动本身就是风险。Multi-Agent 架构划小闭环：撮合大脑居中，两侧为状态上下文与确定性 Harness，下方为执行 Agent 与触达通道，底层仍为推荐/预测/运筹/定价/交易系统。Agent 不替代算法，而是把离散决策组织成连续行动。

**四、策略执行**：运营 35% 精力耗在人工执行。分工为人定目标边界授权、Agent 理解拆解调工具、系统执行动作。运营 Agent 核心是有状态执行 Runtime；所有业务动作必须走标准 Tool 对接真实系统，Harness 完成参数校验、权限、审计、人工反馈。按标准化执行→异常处理→策略建议→经营决策分层放权，往执行端走得越深、往决策端越谨慎。

**五、四层模型**：模型为共同起点；Harness 分帮模型（可删除）与守业务（必写代码），判定法为"假设模型已完美此约束是否仍需"，高代码 Harness 让过程可度量、策略可优化，更自主不等于更好；Dual Loop 内环做对事、外环定正确事，外环发现内环看不见的问题（如配对转化率下降根因在圈选而非对话），LLM-as-Judge 需人工校准、由业务指标验收；业务知识按确定性分流，业务专家是 Agent 的老师和裁判。模型能力大家同起点，拉开差距的是后三层。

**结语**：Agent 的价值在于把原依赖人的开放式工作变成可度量、可持续改进的系统能力，拓展的是技术能解决业务问题的边界。
