# Pi 支持沙箱吗：从什么是沙箱，到 Pi 的两层隔离

> Pi 没有 `--sandbox` 开关——隔离改变的是"Pi 在哪跑"（进程边界/工具后端）而非"怎么跑"。本文基于 Pi 官方文档与源码（2026-10）讲清沙箱原理与 Pi 的两层隔离：脚本级沙箱把模型写的编排代码关进"只有工具、没有操作系统"的运行时；进程级隔离有五种做法（Plain Docker、Docker Sandboxes、OpenShell、Gondolin 微虚拟机扩展、命令沙箱示例扩展），只有把整个 Pi 放进容器/虚拟机才能覆盖扩展与 MCP 工具。核心心法：沙箱是"能力限制"不是"行为审查"，你暴露什么它就能碰什么。相关：[[2026-10-14-pi-setup-mcp-codemode-guide]]

## 核心要点

1. **沙箱本质**：有边界的自由——不审查代码想干什么，只决定它能碰到什么（文件、网络、凭据、进程）；识别会漏，环境不会漏；保证的是影响范围而非绝对安全。
2. **四条实现路径（弱→强）**：能力收窄的运行时（受限解释器）→ OS 级限制（macOS sandbox-exec、Linux bubblewrap）→ 命名空间隔离（容器）→ 硬件虚拟化（VM/微虚拟机），共同动作都是收窄"可达面"。
3. **Pi 默认不沙箱**：工具以启动账号的权限直接运行。官方立场——"把模型生成的命令和代码当作不可信"，看会话、项目信任、审阅 diff 都不构成安全边界；整体跑在容器/VM 里通常是实践中最强选项。
4. **声明一次即可**：脚本沙箱启用代码执行扩展后自动生效；命令沙箱扩展加载即按配置常驻（默认开启，`--no-sandbox` 临时关）；整体隔离在 Pi 外部部署时声明。安全不靠"每次记得"，用户命令拦截器出错即 fail-closed 阻断。
5. **三个"假沙箱"**：项目信任只管加载哪些项目资源；默认工具列表是"有什么能力"而非"关在哪"；逐步批准/看 diff 不构成边界。
6. **脚本级沙箱**：模型写 JavaScript 编排工具调用，运行时无文件系统/网络/进程/环境变量，只能碰注册进来的工具；有输出清单与限额超时；只适合编排过滤，跑不了通用程序。⚠️ 脚本里调用的命令工具仍以宿主权限执行。
7. **命令沙箱（示例扩展）**：用系统机制只关"跑命令"（含模型直调、脚本调用、用户 `!` 命令），全局+项目两级配置项目优先；四类清单：禁读路径（默认含密钥目录）、允许写路径（当前目录/临时目录）、禁写文件（.env/密钥）、域名白名单（默认只放行包仓库与代码托管）。但读写改搜等六类文件工具完全不受约束。
8. **Gondolin 工具级隔离**：覆盖 read/write/edit/bash/ls/find/grep 七个内置工具+用户命令，宿主目录挂进微 VM；但其他扩展、MCP 工具、宿主 Pi 进程不在内，且命令继承宿主环境变量，不是凭据边界。
9. **整体隔离才是全集**：容器/托管沙箱能把所有工具、扩展、MCP 工具及子进程一起关进去；Docker Sandboxes/OpenShell 支持真凭据留宿主、由代理代填。三层可叠加，想让模型触发的所有动作都在边界内只有整体隔离一条路。
10. **选型顺序**：先想防谁 → 再想必须暴露什么 → 最后选工具；能只读别可写，能拷进拷出别直接挂载；官方亦承认容器有网络即无法证明 agent 代码从不用网。

## 正文

### 沙箱原理

沙箱一词来自游乐场沙坑：边界内任意折腾、出不去。它换来四样东西：限制可达面（让 AI 自己动手的前提）、限制影响范围（写坏了丢掉重建）、让试错变便宜（最贵的是回滚而非算力）、让结果可复现可审计（评测与回归的基础）。

### Pi 的两层隔离与五个方案

- **脚本级**（能力收窄路径）：代码执行扩展让模型写小段 JS 调工具，脚本世界里没有系统调用，攻击面靠"不给"而非"拦着"。
- **进程级五种做法**：Plain Docker（全部进容器、凭据传入）；Docker Sandboxes 托管沙箱（凭据留宿主代理代填，"不要在沙箱里登录"）；OpenShell（策略控制凭据与推理路由）；Gondolin 扩展（Pi 留宿主、7 个内置工具挪进微 VM）；命令沙箱示例扩展（Pi 与文件原地不动，仅命令受 sandbox-exec/bubblewrap 约束）。后两种方案宿主上的 Pi 进程与其他扩展仍在边界外。
- **官方自陈漏洞**：读写挂载、挂载代理目录（凭据/设置/会话全交出）、环境变量传入、网络出口均可成为破口；源码见 `examples/extensions/sandbox/index.ts` 与 `examples/extensions/gondolin/index.ts`。
