# 微博盘点：5 个实用的 GitHub 开源 Skill/Agent 工具

- **ffmpeg-skill**：本地 FFmpeg 视频编辑 skill，42 个工具 + MCP，面向 Claude Code / Cursor / Codex，无云端、无需 API Key。

## 正文

> 今天又翻了下 github 热榜的开源项目，很有意思，有各种 skill 和 agent 工具，比如视频图像剪辑、爬虫、office 等等，相当的实用。

1、ffmpeg-skill：ffmpeg 作为视频组件家喻户晓。这是一个本地 FFmpeg 视频编辑 skill：42 个工具 + MCP，给 Claude Code / Cursor / Codex 用，无云端无 API Key。

2、univer：让自己的软件具备 office 办公能力。这是可嵌入产品的 Office SDK，支持编辑、计算、协作与文件处理，同时面向人与 AI agent。

3、firecrawl：这个爬虫框架超级火。是给 agent 用的网页搜索与爬取基础设施，据说接入了 550+ 数据源。

4、CLI-Anything：实用的 CLI 搭建工具。它能把任意软件变成 agent 可调用的 CLI，配套 CLI-Hub 统一入口。

5、minimind：自己搭小模型必备组件。这个仓库包含了从零训练一个 64M 参数小模型的完整教程与代码，两小时内可跑通。
