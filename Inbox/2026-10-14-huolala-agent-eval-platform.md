# 货拉拉业务 Agent 评测平台的工程实践与深度思考

> 货拉拉质量保障部介绍自研的业务 Agent 全生命周期自动化评测平台。针对 LLM 概率输出、工具调用链长、性能维度跃迁导致传统断言与单点打分失效，平台经"人工盲测→离线数据集+单一 LLM 裁判→全生命周期平台"三代演进，落地六大工程支柱：多协议资产纳管、测试数据合规准入、多模复合智能裁判、评测计划与全景报告、LLM 性能压测、CI/CD 门禁闭环。已接入 114 个智能体、沉淀 16,337 个黄金用例，回归提效 5~10 倍，上线合格率 98.5%，线上缺陷率下降 85%。

## 核心要点

1. **为什么难**：确定性断言失效；意图理解→参数提取→工具选择→结果组装→规划修正链路长，错误逐级传导；性能要看 TTFT/TTLT/TPS 而非仅 QPS。
2. **三代演进**：人工盲测与 Excel 用例 → 离线 Benchmark + 单一 LLM-as-a-Judge（有幻觉偏见、脱离流水线）→ 规则+智能裁判+门禁+压测+线上巡检的闭环平台。
3. **资产与协议**：评测实验室多租户隔离；纳管自研工作流/模型平台与自定义 HTTP/SSE 服务；关联代码、Prompt、知识库切片版本保证可复现；三级拦截器（TASK/SESSION/REQUEST BEFORE）动态注入参数，Groovy/JSONPath 清洗异构输出。
4. **数据准入**：发起前全量扫描环境标识、Schema、必填字段、JSON 合法性，1 条不合规即熔断，杜绝"带病评测"污染生产。
5. **复合裁判**：5 类确定性规则（结构化校验/正则/硬匹配/关键词/Embedding 语义相似度）保底；平台-Agent-用例三维 Judge Prompt 动态组合；并发多次采样、去极值取均值、方差超阈值转人工。
6. **Session 级评分**：红线违规（违规承诺、数据泄露、越权写）一票否决穿透全会话；轮次权重前轻后重，考验长程记忆。
7. **客观+主观+人工闭环**：规则守底线、LLM 裁判拉上限、专家复核样本沉淀为黄金集反哺裁判 Prompt。
8. **门禁与压测**：准入跑冒烟集、准出全量基准比对目标分，不达标阻断发布；自研压测引擎支持固定/爬坡并发，精测 SSE 流式 TTFT/TTLT/RPS/失败率；线上分钟级巡检告警。
9. **成效**：回归从天级→小时级（5~10 倍），复杂场景 Bug 检出率 <40%→92%；拦截缺陷中意图理解 33.84% + 工具执行 31.12% 占近 2/3，是单点打分最易漏的环节。
10. **未来方向**：红队 Agent 对抗生成用例、Multi-Agent 链路评测（通信/死锁/状态一致性）、评测驱动 Prompt 自动调优与微调数据飞轮。

## 正文

### 评测之难与范式演进

Demo 惊艳但上线即漂移：同一场景口径不一、复合查询反复调同一接口直到 Token 耗尽、Prompt 微小扰动即答非所问、高并发下 TTFT 从 800ms 飙到 5s。单步推理"都合理"但端到端结果错误，改一处 Prompt 常修好一个 Bug 引入三个缺陷。根因是确定性断言失效、动态决策链路上游偏差被下游放大、性能度量维度跃迁。货拉拉的评测体系因此从人工点测、离线数据集加单一裁判，演进为嵌入发布流水线的第三代平台。

### 六大支柱的工程落地

- **资产治理**：命名空间多租户隔离，统一 Agent 元数据模型，原生支持 SSE，resultPath/resultType 精准提取；调用链拓扑支持 ANY/ALL 匹配，按业务域、能力项、风险等级等多维标签下发用例。
- **数据合规**：强制测试环境标识、禁止未脱敏生产数据；点击"发起评测"第 0 毫秒执行 checkAgentInfoAndCases 全量扫描，返回具体到用例与字段的诊断报告。
- **智能裁判**：硬事实交给毫秒级规则引擎（正则校验订单号/金额、结构化校验 Tool Calling 入参），开放回答交给分层 Prompt 裁判并做抗波动聚合；多轮对话中任何一轮触发超级红线即整 Session 封顶，越靠后轮次权重越高。
- **计划报告**：按能力项设目标分与权重，版本间基线横向对比，功能+性能+安全聚合看板，报告自动推送飞书群。
- **性能压测**：固定并发与线性爬坡模拟早晚高峰，输出 P99/TTFT/TPS 全套指标支撑容量规划与模型选型。
- **门禁闭环**：低分雷达筛专项缺陷，专家改分沉淀优化数据；核心 AI 平台发布关键节点 100% 纳管。

### 业务收益

平台执行功能评测 11,063 次、前置拦截缺陷 669 个、压测 307 次。AI 邀约业务在需求吞吐 +80%（月均 2.2→4.0 个）的同时，月均发布从 33 次降到 14 次，质检 Badcase 降 20%，释放算法人力 41.5 人天/月。头部三个项目贡献约 85% 评测量并拦截 60% 核心缺陷，验证平台既能扛高频回归也能深挖复杂工具链隐患。
