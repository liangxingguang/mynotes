# 微博推荐：GitHub 万星项目《自学是门手艺》——教的不是编程，是学会学习

> 微博帖推荐 GitHub 1.7 万星项目《自学是门手艺》（selfteaching/the-craft-of-selfteaching）：以 Python 为入口讲自学方法论，目标是让人成为"能持续学新东西的人"。

## 核心要点

1. **定位**：编程只是入口不是终点，核心是"怎么学会学习"。
2. **结构三块**：为什么自学值得做 → 以 Python 为例过基础（函数、递归、测试）→ 拆难题与防注意力跑偏。
3. **适合人群**：想练长期学习能力的人，而非只想当程序员的人。
