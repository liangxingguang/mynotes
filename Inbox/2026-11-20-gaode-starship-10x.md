> **摘要**：星舰10X 把成熟 Coding Agent 的执行能力接入团队研发过程，解决"Agent 能写代码、工程师仍要不断补背景/对齐目标/检查覆盖"的问题。核心是知识库与长期记忆（Memory）分工：知识库给业务概念/模块关系/源码入口（渐进式披露四层），Memory 保留工作方法供下次起点。知识分仓库知识库与跨域 KBase，质量检查分脚本机械核对与 Agent 语义审查两条互补路径，经验经会话层→个人层→共享层三层提炼。以双仓缓存默认规则调整为例说明跨仓交付路径；2026 年 4-9 月已核验 1030 项开发任务、至少 676 项形成 MR。

## 核心要点

- **定位**：星舰助手通过主会话承接目标，可展开执行或组织成任务；用户可补条件纠偏，问题与产物返回主会话；平台用任务/工作流组织阶段、产物与必要决策，执行 Agent 在仓库与运行环境中完成具体工作，代码评审/测试/发布仍来自团队已有研发系统。
- **知识与经验分工**：知识库说明"系统实际怎样实现"（仓库知识库：模块职责/调用关系/代码入口；跨域 KBase：术语/业务规则/跨系统架构/操作流程），Memory 提醒"遇到这类问题先查什么"。执行 Agent 拿到目标约束后仍需调工具核对当前事实。
- **渐进式披露四层**：项目入口→架构总览→模块摘要→源码，Agent 按问题决定读到哪层，需确认执行顺序/条件分支/副作用时再进源码与配置；每份模块摘要独立可读并提供继续查证入口。
- **知识质量双路径**：脚本核对入口引用可达、代码版本可定位、关联源文件变化等机械信号；Agent 沿源文件指针读代码做语义审查；工程师裁决哪些发现进入正式知识。区分"当前实现"（代码配置）与"期望规则"（业务负责人确认）。
- **Memory 三层提炼**：会话层存经验候选→个人层从≥2 个独立任务提炼稳定做法→共享层选可迁移实践、脱敏后供团队；个人记忆按用户隔离，共享经验系统自动提炼发布；保留来源、适用条件与验证状态。
- **跨仓案例**：统一两仓默认缓存键前缀，请求/解析侧改回退值、聚合侧同步数据源默认值与测试常量，任一侧遗漏两端找不到同一份数据；星舰把约束写进整体方案与逐仓产物，两份 MR 均已合入。
- **支撑数据**：2026 年 4-9 月核验 1030 项开发任务，至少 676 项形成/更新 MR（占比≥65.6%），7 月峰值 94.2%（172 任务中 162 项有 MR、175 条评审）。
