# Pi School 官方课程主页：在 Pi 里边用边学的免费 Agent 入门课

> Pi School 是 Pi（开源终端 Agent harness）的官方免费课程：无需账号、不收集数据。独特之处在于「课在 Agent 里上」——只有安装课在浏览器完成，之后每节课给一段提示词贴进 Pi，由 Pi 本人带着你学并回传完成状态。面向有命令行基础的普通用户和资深开发者。

## 核心要点

1. **Pi 定位**：免费开源的本地 Agent harness，可读写文件、写代码、跑命令、操控其他应用；支持 15+ 模型提供商（Claude/GPT/Gemini 等）。
2. **设计哲学**：核心保持极简，不内置 sub-agent / plan mode，靠 extensions、skills、prompt templates、MCP 自行扩展。
3. **上课方式**：Lesson 1（安装）在网页完成，其余课程全部在 Pi 内部交互进行——复制提示词给 Pi，它当讲师、自动标记完成并实时同步回网页。
4. **课程内容**：安装配置、用 AI 写改代码、信任模型、skills/模板/扩展、会话历史导航与分支、做网站/游戏等创意项目。
5. **门槛**：免费永久、无需账号、不收集个人数据；只需基本的命令行操作能力。
