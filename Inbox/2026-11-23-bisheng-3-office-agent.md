# 一个能平替 WorkBuddy 和豆包工作的开源办公 Agent，来了！支持私有化部署

> Dataelem 团队开源的企业级办公 Agent 平台 BISHENG 3.0：桌面端基于 DeepSeek Harness（DSH）开发，主打私有化部署、数据不出企业边界，定位 WorkBuddy/豆包工作的开源平替。文章以项目汇报（Chat 模式）与销售数据整理（Work 模式）两个真实任务实测全流程，并介绍企业侧的模型/技能/知识权限管理、外部 Agent 接入与员工应用托管能力。

## 核心要点

1. **定位与形态**：BISHENG 3.0 由 DSH Desktop 桌面端 + BISHENG 企业平台组成；DSH Desktop by Dataelem 已有 100 万+下载、20.8K GitHub ⭐。模型自选、知识库自建、权限自管，代码公开（github.com/dataelement/bisheng），可部署在自有机房/私有云。
2. **两种工作模式**：Chat 偏云端——复杂任务自动转任务模式，界面可见工具调用与执行进度；Work 偏本地——选定授权目录，直接在本地跑文件任务，产出直接存本地。产出的 Word/Excel/PPT 可继续修改、迭代到满意。
3. **实测一·项目汇报（Chat）**：上传会议纪要+进度跟踪表，引用知识空间产品方案，提示词要求按公司周报模板生成五部分汇报；系统自动检索知识→分析材料→调用 Word 技能生成，可在同会话持续提修改要求，上下文保持不丢失，最终文件可下载或上传知识空间团队共享。
4. **实测二·销售数据 Excel（Work）**：本地 CSV 经提示词生成含月度汇总/区域分布/产品线拆分的工作簿，用 Excel 公式而非写死数值；后续一句话改预算（"华东区 Q4 推广预算调到 65 万"）即可联动更新合计与图表。
5. **企业管理能力**：模型管理（接入与部门级授权，Chat/Work 共用月度积分账本+倍率）；技能与工具授权（工具管动作、技能管方法，工具权限各自审批）；知识空间支持文件级权限，检索时按权限过滤；用量审计（调用记录/token/积分）；内容安全（敏感词审查+桌面端调用留痕）。
6. **不强制替换现有工具**：员工习惯的 WorkBuddy、千问办公、Codex 等外部 Agent，安装 BISHENG 知识检索技能并配密钥即可接入企业知识，管理员统一控制接入开关、密钥有效期与访问范围。
7. **应用托管**：员工本地 Vibe Coding 的小应用可提交平台，自动预检+密钥扫描、发布审批后上架应用中心，并可接入平台的用户体系/模型/工具/知识库等基础设施。
8. **开源与商业化**：客户端代码同样开源，可定制换 LOGO/改界面/加技能；基础功能开源，企业旗舰版提供商业能力，已服务中国气象局、汇丰、博世、中国移动、中粮、中金等头部组织。

## 正文

文章为 BISHENG 3.0 产品体验长文，结构如下：

- **引子**：办公 Agent（WorkBuddy、豆包工作）体验好，但企业核心资产（会议纪要、方案、客户资料、财报）要经过第三方服务器，金融/政务/制造等对数据安全有硬要求的行业过不去——需求是私有化部署、数据不出边界。
- **产品形态**：DSH Desktop 登录企业账号后，管理员配置的模型、知识空间、工具、技能直接可用；Chat（云端任务）与 Work（本地文件）两种模式按任务选择。
- **实操一·项目汇报**：以"智慧园区综合管理平台"周报为例，四步走——登录确认资源（企业预置 Word/Excel/PPT 技能）→ 上传材料发起任务（知识空间权限可细到单文件、按部门/用户组授权）→ 拿到初稿后同会话迭代修改 → 下载或上传知识空间共享，完整闭环。
- **实操二·销售数据 Excel**：Work 模式选本地目录放 CSV，要求用公式生成三张工作表，改预算一句话联动更新。
- **企业管理后台**：模型管理（积分账本+额度+模型倍率）、技能与工具授权分工、知识空间文件级权限、用量审计、内容安全（敏感词管控+调用留痕）。
- **外部 Agent 接入**：不强制替换现有工具，知识检索技能+密钥让 WorkBuddy/千问办公/Codex 等接入企业知识，权限规则统一。
- **应用托管**：员工小应用提交平台后经预检、密钥扫描、审批上架应用中心，复用平台基础设施。
- **开源意义**：代码可拉取可定制，部署在自有服务器；开源与商业不矛盾，旗舰版增商业能力，已有多家头部客户。
- **结语**：AI 越强，谁来控制它越重要；对企业而言是在自己基础设施上跑 AI、用自己的规则管数据。
