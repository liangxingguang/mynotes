# 在AI时代回顾互联网黄金时代技术框架

> 一篇技术文化评论：作者在 LLM 重塑编程的节点回望互联网黄金时代，先定义"真框架"（用最小心智负担击穿底层物理复杂度，如 Spring Boot、Koa、Vue、Prisma）与"伪框架"的区别，再剖析大厂高薪催生的"程序员的傲慢"如何人为制造复杂，并指出这种傲慢在 AI 时代借尸还魂——以 DSH 的"微内核、万物皆插件、时空可组合性"等宏大叙事为典型；主张以 Claude Code 式的克制为锚，分清偶发复杂度与根本复杂度，vibe coding 不是工业工程的未来。

## 核心要点

- **真框架的标准**：以最小心智负担击穿底层物理复杂度，API 清晰、稳定、克制（Spring Boot 终结 XML 地狱、Koa/Express 洋葱模型、Vue/React 声明式渲染、Prisma/MyBatis 拉平对象映射），受众广、经得起十年生产环境敲打。
- **程序员的傲慢**：黄金时代的热钱与高薪催生认知偏差——把时代红利误认为个人卓越；为了证明配得上天价薪水，拒绝直白与纯粹，"简单变成耻辱，复杂成了护身符"。
- **伪框架的本质**：人为制造复杂（领域驱动、六边形架构、四层解耦、企业级全家桶、Egg.js、Umi、Weex），受众从来不是代码而是人性的虚荣，靠晦涩黑话把普通工程师挡在门外；生命周期往往随创始者晋升/套现/跳槽而终结。
- **AI 时代借尸还魂**：当年堆砌概念的人成了"AI 布道师"，半天生成上百包、几十万行自己都没看过的黑盒垃圾包装成"颠覆性基建"；以 DSH（Cordis 微内核、万物皆插件、时空可组合性、150+ npm 子包）为例，仍是"概念先行、宏大叙事、框架自嗨"的 DNA。
- **Claude Code 的克制 vs DSH 的虚浮**：Claude Code 就是终端 CLI，核心工具仅 View/Edit/Bash/Glob/Grep，精力全在 Unix 管道、进程控制、Token 预算剪枝、Git Diff 原子性这些底层；DSH 则把实现与文档全盘外包给大模型，连命令行参数都不存在，是典型的"黑盒许愿"。
- **复杂度二分法**：《人月神话》的偶发复杂度（技术摩擦：繁琐 API、样板代码）与根本复杂度（业务推演、状态机、竞争条件、数据自洽）；大模型能粉碎偶发复杂度，但无法抹平根本复杂度。
- **AI 时代工程师的姿态**：① 把规格与类型当锚点，接口文档、结构化类型、关键路径单测成为系统唯一的"防腐层"；② 精力向根本问题收敛（模块权责、数据一致性、优雅降级）；③ 保持对每处变更的知情权，认真审阅每一次 Git Diff——对系统状态保持诚实清醒是底层操守。
