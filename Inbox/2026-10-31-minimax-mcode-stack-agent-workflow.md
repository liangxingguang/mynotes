# MiniMax 开源「mcode-stack」：用 MiniMax Code 写 MiniMax Code 的全套工作流

> 微博博主「蚁工厂」转发 MiniMax 开源项目 mcode-stack（github.com/MiniMax-AI/mcode-stack）：一套"用 MiniMax Code 写 MiniMax Code"的全套工作流。聚焦 AI 编程工作流里的五个核心问题——代码质量保持、subagent 拆分判断、长命令等待、长会话防"变傻"、每轮上下文注入管理。

## 核心要点

- **开源项目**：MiniMax-AI/mcode-stack，定位是 AI 编程工作流参考实现，非单一提示词。
- **五个关键问题**：AI 代码质量怎么保持、任务该不该拆 subagent、长命令怎么等、长会话怎么不变傻、每轮往上下文里塞了什么。
- **价值点**：工作流把"提示词管不了的事"交给机制（执行记录、上下文管理、验收反馈），与 [[2026-10-30-ai-coding-eight-stage-workflow|AI 开发八阶段工作流]]思路相近。
- **传播度**：转发 112 / 评论 12 / 赞 127（2026-10-29 发布），评论区有人将其与自研 agent（codem）对标，认为验收与可信度工具值得借鉴。
