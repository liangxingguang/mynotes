# 这门免费课表面在教 Pi，其实在教你 Agent 到底怎么工作

> 一门 15 节免费 Pi 课程的体验推荐：上课方式很特别——第一节自己装好 Pi，第二节起"老师"就是 Pi 本身，网站只给一段提示词，复制给 Pi 后由它带着讲解和操作。作者认为它本质是一门 Agent 入门课，Pi 只是教材，真正可迁移到 Claude Code、Codex 的知识是：上下文怎么管、工具什么时候加、走错了怎么退、何时放手让 Agent 自己解决。

## 核心要点

1. **为什么用 Pi 学 Agent**：默认只给模型读文件、改文件、跑命令三个最基本能力，东西少才看得清哪一步是模型在判断、哪一步是 Agent 在执行。
2. **Agent 进入工作环境**：接上模型只是第一步，还要定模型、项目、规则、权限；课程连某些登录方式可能违反服务条款、有封号风险都会提前提醒。
3. **上下文为什么会跑偏**（作者认为最值得看的部分）：Agent 眼前堆着读过的文件、命令输出、工具结果和历史回复，压缩成摘要后细节易丢。建议——任务换了就开新会话、别轻易压缩，真要压缩就指明什么信息最重要。
4. **对话即树状分支**：Pi 把对话看成一棵树而非直线，走错可退回任意节点重走且原尝试保留，类似版本控制的存档点；陷入"犯错→纠正→更错"循环时，别再补 prompt，开新会话或回退节点更有效。
5. **能力最后再加**：先把系统跑顺，再按需加 Skill（给 Agent 的 SOP）、MCP（接外部系统）、Extension（改 Agent 自身）——先简单，确有需要再增加复杂度。
6. **核心习惯转变**：少告诉 Agent 怎么做，多告诉它你要什么（如"看看项目，整理一份项目说明"，让它自己想办法）；Agent 时代比记按钮更重要的是把目标说清楚。
7. **适用建议**：后附 11 个练习（做网站、控制浏览器、整理邮件、处理图片视频），不只是 Coding Agent 教程；终端零基础开头有门槛，不必打卡学完，前半段模型/上下文/会话/分支部分已值回票价。

## 正文

文章推荐免费课程 Pi School（共 15 节）。课程形式：每节课网站只提供一段提示，学习者复制给 Pi，后续讲解与操作都由 Pi 自己引导，在"用 Agent"的过程中理解 Agent。

作者把 15 节课压缩成三个问题：①Agent 怎么真正进入工作环境——模型选择、项目目录、遵守规则、权限边界缺一不可，课程甚至会提示登录方式的封号风险；②为什么聊久了会跑偏——多因上下文堆积与摘要压缩丢细节，对策是换任务开新会话、压缩时声明重点；③能力为什么要最后加——Skill/MCP/Extension 都是外挂，应在基本流程跑顺后按需引入。

Pi 的树状会话设计让每段对话都有可回退的"存档点"，原尝试不会丢失；作者结合自己用 Claude Code、Codex 的体验强调，工具会一直换，真正值得学的是上下文管理、工具引入时机、错误回退与放手让 Agent 自主完成目标的判断力。
