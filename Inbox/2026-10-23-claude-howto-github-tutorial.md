# claude-howto：一套完整的 Claude Code 开源教程

> GitHub 开源仓库 claude-howto（luongnv89）整理了一套 Claude Code 完整教程，10 个模块从基础到高级，随版本迭代持续更新，完整学完约 11–13 小时，附自评测试定位起点。

## 核心要点

- 多数用户只用到 Claude Code 约 10% 的功能
- 教程覆盖 10 个模块：Slash Commands、Memory、Skills、Subagents、MCP、Hooks、Plugins 等
- 免费开源、持续更新；仓库内有自评测试，可从任意模块切入
- 地址：https://github.com/luongnv89/claude-howto

## 正文

开发者 luongnv89 在 GitHub 维护的 claude-howto 仓库，把 Claude Code 的能力体系整理成 10 个模块的完整教程：从最基础的 Slash Commands（快捷指令），到 Memory（跨对话记住项目配置）、Skills（预写能力模块自动调用）、Subagents（任务拆分给专属助手并行处理）、MCP（对接 GitHub/数据库等外部工具）、Hooks（事件触发自动脚本）、Plugins（打包成整套方案一键部署）。

完整学完约需 11–13 小时，但无需一次学完：仓库提供自评测试帮助定位起点，哪怕只花 15 分钟复制一个 slash command 模板也能立刻见效。教程随 Claude Code 版本迭代同步更新。
