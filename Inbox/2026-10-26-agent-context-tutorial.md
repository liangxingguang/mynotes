# Agent 入门教程：上下文里的 Agent

> 微博博主「蚁工厂」推荐的可交互 Agent 入门教程（nano-ai.tech/agent/）：把 Agent 讲成一个 while 循环——调模型、执行工具、结果写回上下文、再调模型。逐章演示上下文每转一圈如何增长、哪里会出问题、各种 Agent 技巧在上下文里做了什么，每章可「播放」或逐格步进。

## 核心要点

- **核心视角**：Agent = while 循环（调模型 → 执行工具 → 写回上下文），没有神秘感
- **教学法**：结合实际代码运行步骤讲解，可视化观察上下文每轮的变化
- **交互式**：每章可点「播放」自动演示，或一格一格手动步进
- **覆盖内容**：上下文增长规律、上下文引发的问题、常见 Agent 技巧的上下文层面本质
- **教程地址**：[nano-ai.tech/agent/](https://nano-ai.tech/agent/)
