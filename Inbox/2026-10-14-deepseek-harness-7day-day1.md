# 7天学懂 DeepSeek Harness 实操手册（Day 1：装好之后的第一小时）

> DeepSeek Harness v0.2 预览版（9.29 发布，提供 macOS/Windows 桌面端）7 天系列教程的第 1 天，专治"装好了不敢下手"：认识界面五站、申请并填入 DeepSeek API key、选对模式，三件事走完即可开工。后续六天为派活、分身、排错、插件、换脑、造扳手（本文不含）。

## 核心要点

1. **界面五站**：模型选择器（Flash 日常够用，重活上 Pro；推理等级默认，答浅了再调高）→ 派活输入框 → 工作区路径（开工前确认指向正确文件夹）→ 右上角模式按钮 → 齿轮设置。
2. **办钥匙五步**：DeepSeek 开放平台注册登录 → API keys 菜单创建 → key 只显示一次须立即复制保存 → 按量计费先充最小额度 → Harness 设置中粘贴 key，发测试消息验证。
3. **key 安全**：等同钱包密码，不发群、不截图、不外传，泄露立即重置。
4. **四种模式速查**：标准模式（新手无脑选，文件/Shell/搜索/计划/子 Agent/工作流全配齐）；PTC 模式（把多次工具调用打包成一段程序跑，省 token 但调试难，建议标准模式用满一个月再碰）；极简模式（仅命令行+文件编辑，用于裸测新模型，日常别用）；创造模式（自检并自造插件/模式，第七天主讲）。
5. **三大新手坑**：工作区路径没核对导致文件落错地方；误切极简模式却嫌模型笨；测试无反应先查 key 是否粘错、再查余额。
6. **自检指令模板**："报告当前工作状态：当前模式和模型；有哪些能力和插件（按用途分组）；当前工作区路径是否指向 ____，不确定的说不确定"——装新插件前后各跑一次可对比差异。
7. **背景信息**：Harness 是调用 DeepSeek 模型的桌面工位（Agent 客户端），模型按量付费；本手册共 7 篇分文章发布，本篇仅 Day 1。

## 正文

### 界面动线与 API 配置

作者把新手第一小时压缩为"认全五个地方、插好一把钥匙、选对一个预设"。模型档位上日常任务选 Flash，推理等级管思考深度、越深越烧 token 越慢，保持默认即可。API key 在 DeepSeek 开放平台创建，生成后只展示一次，需先充少量余额再回到 Harness 齿轮设置中填入，看到测试回复才算真正装完。

### 四种模式的取舍

四种模式本质是四套出厂预设模板而非四种功能。标准模式是全能工位，整理文件、写文档、小统计都能完成；PTC 适合几百个文件批量检查改写等大量重复工具往返场景，一次打包执行减少对话轮次；极简模式是"素颜"裸测环境，接入新模型时测其原生能力；创造模式允许 Agent 检查自身插件并现场造装，留给系列最后一天。

### 第一天的检查清单

派活前扫一眼工作区路径；确认停在标准模式；用自检指令让 Agent 报告模式、模型、插件清单与工作区，后续装完插件再跑同一指令即可对比新增能力。
