# AI 生态系统的 11 个维度

> 把现代 AI 工具栈按「底层模型 → 能力增强 → 工程基建 → 上层应用」链路拆成 11 个维度，每个维度给出代表工具清单，是一张实用的 AI 技术生态全景地图。

## 核心要点

1. **大语言模型**：基础推理与生成能力，代表：GPT、Claude、Gemini、Llama、Mistral、Cohere、Hugging Face、Ollama、vLLM。
2. **智能体式 AI**：智能体编排与多智能体协作框架，代表：LangGraph、CrewAI、AutoGen、Microsoft Agent Framework、LlamaIndex Workflows、AWS Strands Agents、CAMEL、Agno。
3. **RAG**：把外部知识接进模型，代表：LangChain、LlamaIndex、Haystack、DSPy、RAGflow、GraphRAG、Unstructured、EmbedChain。
4. **向量嵌入**：文本/数据转向量，代表：OpenAI Embeddings、Cohere Embed、Voyage AI、Sentence Transformers、BGE、Vertex AI、Azure OpenAI Embeddings。
5. **MCP**：模型与外部工具/数据源的连接标准，代表：MCP SDK、FastMCP、MCP Registry 及 GitHub、Slack、PostgreSQL、Google Drive、Filesystem 等 MCP Server。
6. **AI 安全**：护栏、隐私与内容风控，代表：NeMo Guardrails、Guardrails AI、Presidio、Lakera Guard、Prompt Security、Protect AI、Azure AI Content Safety、Bedrock Guardrails。
7. **可观测性**：链路追踪、评估与监控，代表：LangSmith、Langfuse、Arize Phoenix、W&B Weave、TruLens、Ragas、Promptfoo、Helicone。
8. **记忆**：长期/短期状态与上下文持久化，代表：Memo、Zep、Letta、LangGraph Memory、Redis、PostgreSQL、Neo4j、Chroma。
9. **AI 智能体**：厂商级 Agent 开发套件与托管服务，代表：OpenAI Agents SDK、LangChain Agents、PydanticAI、Semantic Kernel、Google ADK、Bedrock AgentCore、Azure AI Foundry Agent Service。
10. **自动化**：工作流与任务编排，代表：n8n、Zapier、Make、Power Automate、Temporal、Airflow、Prefect、Kestra、Pipedream。
11. **向量数据库**：向量检索与存储底座，代表：Pinecone、Weaviate、Qdrant、Milvus、Chroma、pgvector、Elasticsearch、Redis、MongoDB Atlas Vector Search。
