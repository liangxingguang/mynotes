# 三万字长文：大语言模型从零入门

> 一篇面向零基础读者的 LLM 系统教程：用"预测下一个 token"一条主线串起信息论、神经网络、Transformer 到 ChatGPT 后训练与局限，只用加减乘除和对数，配手算例子。结论：把预测下一个 token 做到极致就是在通过图灵测试；模型的能力与幻觉等局限同源于此。

## 核心要点

1. **语言模型本质**：给定前文输出下一个 token 的概率分布，逐 token 自回归生成；预测得足够准即通过图灵测试，因此必须掌握知识、推理、意图等。
2. **信息论三件套**：信息量 = −log₂p（折半次数）；熵是真实分布的平均不确定性（交叉熵下界）；交叉熵衡量模型估计的实际码长，"自信地猜错比不知道更糟"——它就是训练损失函数。
3. **神经网络**：神经元 = 加权求和 + ReLU 非线性；Softmax 把 logits 变概率；通用逼近定理保证表达能力；梯度下降+反向传播调参；LayerNorm 稳数值、残差连接让网络可叠上百层；压缩与泛化同源（找到可复用规律）。
4. **Transformer**：嵌入向量承载语义；注意力按 QKV 有选择地收集前文，因果掩码防偷看；多头并行关注不同关系；RoPE 注入相对位置；前馈网络（约 2/3 参数）负责加工；每块 = 注意力 + FFN，外套残差与 Pre-Norm，堆叠几十层。
5. **生成控制**：贪心/Top-k/Top-p 截断长尾；温度调节保守与大胆；采样只能在模型概率内选择，救不回错误的概率表；已生成的 token 不能撤回。
6. **后训练四步**：预训练得"只会续写"的基座 → SFT 学助手格式（质量 > 数量，LIMA 仅 1000 条示范）→ RLHF/DPO 对齐人类偏好（防奖励投机）→ 推理强化学习只判对错（R1-Zero 数学正确率 15.6%→71%，自发学会长思考）。
7. **多模态与 Agent**：工具调用 = 模型写格式化指令、外部执行后把结果拼回上下文；图片切块转 token；对模型而言一切皆 token。
8. **规模与局限**：损失随参数/数据/算力按幂律下降但不低于语言自身的熵（约 2.4 bit/token）；幻觉源于目标是"像"非"真"、零散事实记不牢、评测奖励猜、文字不可撤回，越具体的人名/数字/引用越易错，需提供资料、允许说不知道、多方核实。

## 正文

### 语言模型的本质

以"他口渴了，于是喝了一杯____"等接龙游戏贯穿全文：模型处理的最小单位是 token（可能是字或词），输出一张候选概率表，循环采样接到前文即生成整段话。文章从图灵 1950 年"模仿游戏"论证：模型从海量人类文字中学"人接下来会写什么"，分布与人完全一致时文字不可分辨，故极致的下一 token 预测即智能；要预测得准必须具备知识、语法、推理等。随后用 1–8 猜数字游戏讲信息论：折半提问每次得 1 bit，单个结果信息量 I(x)=−log₂p(x)，熵是按真实分布的平均信息量，交叉熵 H(p,q)=−Σp(x)log₂q(x) 是按模型估计编码的实际平均码长，永不低于熵；在真实文本每个位置取 −log₂q(真实 token) 的均值即训练损失，无需知道真实概率。

### 神经网络

人写规则和 n-gram 统计表都会死记，神经网络靠嵌入空间举一反三。文章依次讲：神经元（权重+偏置经 ReLU 弯折，非线性是叠层有意义的前提）、Softmax（指数归一化得到概率）、通用逼近定理（足够宽的一层可逼近任意连续函数，深层更省神经元）、梯度下降（沿损失山坡下行，学习率过大震荡过小则慢，不保证全局最优；Softmax+交叉熵的梯度恰为"预测概率−答案"）、反向传播、层归一化/RMSNorm（把每层数值拉回标准范围、稳定训练）、残差连接 y=x+F(x)（"批注而非重抄"，给梯度一条乘 1 的直通路，使 152 层可训练）。过拟合与泛化借"背答案 vs 学会乘法"说明：发现规律同时带来压缩与泛化（最小描述长度原则），用验证集损失辨别是否死记。

### Transformer

编号无语义，故每 token 查嵌入表得到数千维向量，训练让相似上下文的 token 向量靠近，规律可向没见过的前文迁移。注意力解决"决定答案的词在很远之前"的问题：每个位置用 Q（找什么）与各位置 K（有什么）点积打分，Softmax 成权重后对 V（提供什么）加权平均；因果掩码把未来位置权重置零，使一段文本可并行生成约长度数量的训练题。多头注意力用多组 QKV 分别捕捉搭配、指代、施事等关系（如归纳头支持 in-context 现学）。位置信息原用正弦向量相加，现代模型多用 RoPE——按位置正比角度旋转 Q/K，使分数只取决于相对距离。前馈网络先扩 4 倍宽再压回，是主要的非线性变换与"键-值记忆"载体。完整块为 `x = x + Attn(Norm(x)); x = x + FFN(Norm(x))`（Pre-Norm），GPT-3 96 层、每层约 12d² 参数，总计约 1750 亿。

### 从模型到 ChatGPT

自回归循环遇到结束 token 或长度上限停止，早期错误只能圆场。采样策略：贪心稳定但易重复，随机采样长尾必然出错，Top-k 固定截断，Top-p（核采样）按累计概率动态保留候选；完全可猜的文本没有信息量，故开放写作需要随机ness。温度是分数除以 T 再 Softmax：低温适合代码与事实问答，高温适合创作。基座模型只学会续写、不懂回答且不知停止；SFT 用特殊标记组织的"指令+优质回答"示范训练（通常只对助手部分算损失）；RLHF 分"收集比较→训奖励模型→强化学习"三步，并需约束模型别为钻奖励模型空子而退化（奖励投机），DPO 则跳过奖励模型直接用偏好对优化；可自动判对错的数学/代码任务用推理强化学习，DeepSeek-R1-Zero 无推理示范即自发涌现检查与回溯行为。工具调用、代码执行、联网都是同一套路：模型写结构化调用文本→停下→外部执行→结果作为新前文喂回，多轮循环即 Agent；图像切块经编码器变成 token 与文本同列。规模定律：交叉熵随参数量、数据量、算力按幂律下降（单项扩大 10 倍约剩 80%–89%），可用小模型实验外推大模型；训练算力 ≈6ND；Chinchilla 指出参数数据要配比平衡。损失有不可约下限（自然语言的熵）。幻觉的四个根源及应对，加上知识截止、上下文有限且中间信息易忽略、token 化导致字符/算术出错、迎合用户、相关≠因果等局限表；最终可靠性要以自己真实任务上的表现判断。文末留三个开放问题：当前架构是否最优、能否脱离人类语言数据获得智能、大模型有无自我意识。
