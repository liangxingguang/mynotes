> **摘要**：按 star 排序的 30 个 Agent Skills 清单（2026-11-03 实测），每条一句"替你省什么"加开源地址。头部三名断层领先：Superpowers（31.1 万，TDD 七步方法论）、Matt Pocock Skills（31 万，grill-me/tdd/code-review 日常提效）、ECC（29.6 万，71 agents+314 skills 工程基建）。覆盖代码开发、文档办公、设计多媒体、效率工具、数据五组，Skills 生态已从"有没有"进入"装哪个"。

## 核心要点

- **定位**：不是测评，是按 star 排序的挑选清单——生态最缺"别让我自己挑"的清单，价值在于省掉挑选时间；作者声明未全装，排序本身是实测干活成果。
- **头部三名（断层领先，均超 29 万 star）**：Superpowers（TDD 七步开发方法论，逼 Agent 先计划再写代码、省返工）；Matt Pocock Skills（grill-me 灵魂拷问、tdd、code-review，日常提效直接套）；ECC（71 个 agents、314 个 skills 带安全扫描，工程体系开箱即用）。方法论选 Superpowers、日常提效选 Matt Pocock、搭基建选 ECC。
- **代码开发组（9 个）**：mcp-builder、webapp-testing（Playwright E2E）、gstack（23 件套虚拟工程团队）、GSD（spec 先行再开工，返工少一半）、Trail of Bits Skills（安全审计规则）、superpowers-lab（实验性技能）。
- **文档办公组（6 个）**：Document Skills（docx/pdf/pptx/xlsx 四件套，source-available 非开源）、skill-creator、internal-comms（周报/Newsletter/FAQ 模板）、brand-guidelines、Skill_Seekers（文档/PDF 一键转 Skills）、Claude-Command-Suite（216 命令+12 Skills）。
- **设计多媒体组（6 个，全 Anthropic 官方出品）**：frontend-design（治 AI 味界面）、web-artifacts-builder、canvas-design、algorithmic-art、theme-factory、slack-gif-creator——官方也清楚 Agent 短板在审美不在逻辑。
- **效率工具组（8 个）**：awesome-claude-skills（ComposioHQ，200 条集成目录）、awesome-claude-code、claude-plugins-official、awesome-agent-skills（VoltAgent，1000+ 含 Google/Stripe 出品）、claude-skills（401 个跨职能合集）等目录型仓库。
- **数据组（1 个）**：数据类独立仓库极少，Tinybird/ClickHouse/DuckDB/MongoDB/Redis 查数 Skills 基本都在 awesome-agent-skills 合集中。
- **安装三法**：插件市场（`/plugin marketplace add`）/ npx 直装（`npx skills add`）/ 手动 clone；提醒 star 为 11-03 实测每天在涨，归档库装新地址、装前看 README。
- **核心判断**：Skills 竞争已从"谁功能多"变成"谁被装得多"，31 万 star 与 400 star 差的不是代码是共识；清单给共识起点，装完留删是用户自己的下一轮功课。
