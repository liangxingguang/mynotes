# 这 6 本 GitHub 上的开源 AI 宝典，那是相当有真东西

> 6 个高质量开源 AI 书籍/教程项目清单，覆盖 Agent 工程、AI Infra、深度学习理论、强化学习数学与实战。

## 核心要点

- **《深入理解 AI Agent》**（bojieli，4.9 万 Star）：Agent = LLM + 上下文 + 工具，Harness 工程能力是竞争力；含后训练、Agent 进化、多 Agent 协作 → github.com/bojieli/ai-agent-book
- **《深入理解 AI Infra》**（同作者姊妹篇，4600+ Star）：大模型资源账量化分析——计算量/显存/带宽/功耗估算与系统设计 → github.com/bojieli/ai-infra-book
- **《神经网络与深度学习》蒲公英书**（邱锡鹏，1.9 万 Star）：第二版（理论）+ 通识版（直觉）双电子稿 → github.com/nndl/nndl
- **《强化学习的数学原理》**（1.8 万 Star）：数学视角讲 RL 设计动机，需概率论与线代基础，配套课程播放 270 万+ → github.com/MathFoundationRL/Book-Mathematical-Foundation-of-Reinforcement-Learning
- **《Agentic Design Patterns》中文版**（8K+ Star）：谷歌工程师的 21 个 Agent 设计模式（提示链/路由/并行化/规划/多智能体/RAG/安全/评估），中文站 adp.xindoo.xyz → github.com/xindoo/agentic-design-patterns
- **Hands-On Modern RL**（WalkingLab，4400+ Star）：从 CartPole 到 RLHF/DPO/GRPO 的 26 章实战教程，每章可运行代码+训练曲线 → github.com/walkinglabs/hands-on-modern-rl
