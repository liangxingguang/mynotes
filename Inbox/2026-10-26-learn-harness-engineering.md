# Learn Harness Engineering：开源 Coding Agent 工程课程

> 微博博主「黄建同学」推荐：Walking Labs 出品的开源课程 Learn Harness Engineering，14 讲 + 8 个递进项目，附中文资料与可复用模板。课程围绕 Coding Agent 的工作环境展开——组织仓库、保存进度、控制任务范围、验证 Agent 是否真完成了工作，适合已在用 Coding Agent、想系统改善开发流程的人。

## 核心要点

- **内容**：14 讲 + 8 个递进式动手项目，提供中文资料与可复用模板
- **主题**：Harness 工程——Agent 的工作环境设计：仓库组织、进度保存、任务范围控制、完成验证
- **适合人群**：已经在用 Coding Agent、想系统改善开发流程的开发者
- **环境要求**：可用的 Coding Agent、Git、Node.js / Electron
- **仓库**：[walkinglabs/learn-harness-engineering](https://github.com/walkinglabs/learn-harness-engineering)
